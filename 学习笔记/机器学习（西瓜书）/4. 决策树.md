
## 4.1 基本流程

### 决策树是什么

一棵树，**每个内部节点**表示对某个属性的"测试"，**每个分支**对应测试结果，**每个叶节点**对应一个决策结果（类别）。

形如人类做决策：

```
色泽=? 
├── 青绿 → 根蒂=?
│         ├── 蜷缩 → 好瓜
│         └── 硬挺 → 坏瓜
├── 乌黑 → ...
└── 浅白 → ...
```

### 基本算法：分而治之 (divide-and-conquer) ⭐

**核心思路**：自根至叶递归构建，每次选一个"最优划分属性"。

```
输入：训练集 D，属性集 A
输出：决策树

1. 生成节点 node
2. if D 中样本全属于同一类 C：
       将 node 标记为 C 类叶节点；return
3. if A = ∅ 或 D 中所有样本在 A 上取值相同：
       将 node 标记为叶节点，类别为 D 中样本最多的类；return
4. 从 A 中选择最优划分属性 a*
5. for a* 的每个取值 a*_v：
       为 node 生成一个分支；令 D_v 为 D 中 a* 取值为 a*_v 的样本子集
       if D_v 为空：
           分支节点标记为叶，类别为 D 中样本最多的类   // 注意：用父节点的多数类
       else:
           递归 TreeGenerate(D_v, A \ {a*})
```

### 三种递归返回（终止）情形 ⭐

1. **当前节点样本全属同一类** → 无需划分
2. **属性集为空 或 样本在所有属性上取值相同** → 无法划分（用**当前节点的多数类**作为叶节点类别）
3. **当前节点样本集为空** → 不能划分（用**父节点的多数类**作为叶节点类别）

> 💡 注意第 2、3 种情形的区别：第 2 种用**当前节点**的后验分布，第 3 种用**父节点**的先验分布。

## 4.2 划分选择 ⭐⭐⭐ （本章核心）

**关键问题**：怎么选"最优划分属性 $a^*$"？

**目标**：随着划分进行，希望分支节点所包含的样本**尽可能属于同一类**——即节点的**"纯度 (purity)"** 越来越高。

不同算法用不同的**纯度度量**：

### 4.2.1 信息增益 (Information Gain) —— ID3 算法 ⭐

#### 信息熵 (information entropy)

样本集合 $D$ 中第 $k$ 类样本所占比例为 $p_k$，则 $D$ 的信息熵为：

$$\text{Ent}(D) = -\sum_{k=1}^{|\mathcal{Y}|} p_k \log_2 p_k$$

**直觉**：

- $\text{Ent}(D)$ 越小，$D$ 的纯度越高
- 全是同一类 → $\text{Ent}(D) = 0$（最纯）
- 各类均匀分布 → $\text{Ent}(D)$ 最大（最乱）

#### 信息增益

用属性 $a$ 划分 $D$，设 $a$ 有 $V$ 种取值，划分得到 $V$ 个子集 $D^v$：

$$\text{Gain}(D, a) = \text{Ent}(D) - \sum_{v=1}^{V} \frac{|D^v|}{|D|} \text{Ent}(D^v)$$

**信息增益越大 → 用属性 $a$ 划分所获得的"纯度提升"越大**。

**ID3 算法**：每次选信息增益最大的属性作为划分属性。

#### 缺陷 ⚠️

**信息增益对可取值数目较多的属性有所偏好**——极端情况，若把"编号"作为属性（每个值只对应一个样本），信息增益最大，但毫无泛化意义。

### 4.2.2 增益率 (Gain Ratio) —— C4.5 算法 ⭐

为了解决 ID3 的偏好问题，C4.5 用**增益率**：

$$\text{Gain\_ratio}(D, a) = \frac{\text{Gain}(D, a)}{\text{IV}(a)}$$

其中 $\text{IV}(a) = -\sum_{v=1}^{V} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|}$，称为属性 $a$ 的**固有值 (intrinsic value)**——属性取值越多，$\text{IV}(a)$ 越大。

> ⚠️ **注意**：增益率对可取值数目**较少**的属性有所偏好（偏好和信息增益相反）！

**C4.5 的启发式做法**： **先**从候选属性中找出**信息增益高于平均水平**的属性，**再**从中选**增益率最高**的——避免两种偏好走极端。

### 4.2.3 基尼指数 (Gini Index) —— CART 算法 ⭐

#### 基尼值

$$\text{Gini}(D) = \sum_{k=1}^{|\mathcal{Y}|}\sum_{k' \neq k} p_k p_{k'} = 1 - \sum_{k=1}^{|\mathcal{Y}|} p_k^2$$

**直觉**：从 $D$ 中随机抽两个样本，类别标记不一致的概率。$\text{Gini}(D)$ 越小，纯度越高。

#### 基尼指数

$$\text{Gini\_index}(D, a) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} \text{Gini}(D^v)$$

**CART 算法**：选基尼指数最小的属性作为划分属性。

#### 三个准则对比

|算法|准则|偏好|树形态|
|---|---|---|---|
|**ID3**|信息增益|偏好取值多的属性|多叉树|
|**C4.5**|增益率|偏好取值少的属性（先筛后选）|多叉树|
|**CART**|基尼指数|较稳定|**二叉树**（每次只划分为两支）|

> 💡 **实践中 CART 最常用**——它既能做分类也能做回归（用平方误差代替基尼指数），是 sklearn 中决策树的默认实现，也是 GBDT、XGBoost 的基学习器。

## 4.3 剪枝处理 (pruning) ⭐⭐⭐

**剪枝**是决策树对付**过拟合**的主要手段。

### 为什么要剪枝

决策树如果分支太多，会把训练集自身的特点当成所有数据的特点 → **过拟合**。

### 4.3.1 预剪枝 (pre-pruning)

**做法**：在节点划分**之前**评估——若当前节点划分**不能**带来泛化性能提升，则不划分，标记为叶节点。

- **判断标准**：在**验证集**上的精度是否提升
- **优点**：降低过拟合风险，**显著减少训练和测试时间**
- **缺点**：**贪心**——有些划分当下没收益，但后续划分可能带来大幅提升，预剪枝会错过这些机会，可能导致**欠拟合**

### 4.3.2 后剪枝 (post-pruning)

**做法**：先生成完整决策树，然后**自底向上**考察每个非叶节点——若将该子树替换为叶节点能提升验证集精度，则剪掉。

- **优点**：欠拟合风险小，**泛化性能往往优于预剪枝**
- **缺点**：要先生成完整树，**训练时间开销大**

### 对比总结 ⭐

|维度|预剪枝|后剪枝|
|---|---|---|
|**时机**|划分前判断|完整树生成后自底向上|
|**欠拟合风险**|较高|较低|
|**泛化性能**|一般|通常更好|
|**时间开销**|小|大|

## 4.4 连续与缺失值

### 4.4.1 连续值处理 ⭐

连续属性的取值数目无限，不能直接划分。用**二分法 (bi-partition)**——C4.5 采用的策略：

1. 将连续属性 $a$ 在 $D$ 中出现的 $n$ 个值排序：$a^1, a^2, ..., a^n$
2. 候选划分点集合：相邻取值的中点，共 $n-1$ 个 $$T_a = \left\{ \frac{a^i + a^{i+1}}{2} \mid 1 \le i \le n-1 \right\}$$
3. 对每个候选划分点 $t$ 计算信息增益，选**最优划分点**

> ⚠️ **关键区别**：与离散属性不同，**连续属性在当前节点划分后，仍可在后续节点中再次作为划分属性**（用不同的划分点）。

### 4.4.2 缺失值处理

实际数据经常有缺失值。需要解决两个问题：

**问题1：如何在属性值缺失的情况下选择划分属性？**

- 仅用属性 $a$ 上**无缺失**的样本子集 $\tilde{D}$ 计算信息增益
- 再乘以**无缺失样本所占比例** $\rho$ 作为最终增益

**问题2：给定划分属性，对该属性缺失的样本怎么处理？**

- 将该样本**同时划入所有分支**，但**调整权重** $\tilde{r}_v \cdot w_x$——即按各分支无缺失样本的比例分配权重
- 直观理解：让缺失样本"以不同概率"进入不同分支

## 4.5 多变量决策树 (multivariate decision tree) ⭐

### 单变量决策树的局限

传统决策树的每个节点只对**一个属性**进行测试，对应分类边界都是**轴平行 (axis-parallel)** 的。 对于复杂的分类边界（如斜线），需要很多段才能近似 → 树会很深、很复杂。

### 多变量决策树

节点不再是单个属性的测试，而是属性的**线性组合**： $$\sum_{i=1}^{d} w_i a_i = t$$

**分类边界可以是斜线** → 树更简单、表达能力更强。

- 代表算法：**OC1**
- 也可以是非线性的（如神经网络作为节点），属于**混合模型**思路

> 💡 多变量决策树某种程度上是**决策树 + 线性模型**的混合体——后续随机森林、GBDT 一般还是用**单变量**作为基学习器，因为简单+集成能更稳定地取得好效果。

- 对训练数据**敏感**（小变动导致树结构大变）→ 集成方法缓解
- **轴平行**边界（单变量决策树）表达能力有限

### 1. ID3 为什么对取值多的属性有偏好？举一个极端例子说明。

**原因**：

- 属性取值越多 → 划分后每个子集越**小、越纯** → 子集熵越接近 0 → 信息增益越大
- 信息增益**没有惩罚"取值数量"**

**极端例子：用"编号"作为划分属性**

- 假设西瓜数据集有 17 条记录，编号 1 ~ 17
- 用"编号"划分 → 17 个分支，每个分支只有 1 个样本
- 每个分支的熵 = 0（单一类别，绝对纯净）
- 信息增益 = 原始熵 - 0 = **最大可能值**

但显然"编号"对**新样本毫无预测意义**——这就是 ID3 的缺陷。

**C4.5 的修正**：用增益率 = 信息增益 / 固有值 $\text{IV}(a)$。属性取值越多，$\text{IV}(a)$ 越大，分母变大 → 抵消偏好。

---

### 2. C4.5 用增益率代替信息增益，是否就完美了？还有什么问题？

**不完美**——C4.5 引入了**反向偏好**：

- 增益率对**可取值数目少**的属性有偏好
- 二值属性容易获得高增益率

**C4.5 的实际做法（启发式）**：

1. 先选出信息增益**高于平均水平**的属性
2. 再从中选**增益率最高**的

这是个**两阶段筛选**——避免两种偏好走极端。

**其他问题**：

- 仍只能处理离散属性的**多叉划分**（虽然支持连续值二分）
- 计算开销比 ID3 略大（要算 $\text{IV}(a)$）

---

### 3. 基尼指数和信息熵的关系是什么？为什么 CART 偏爱基尼指数？

**关系**： 两者都衡量**集合纯度**，数学上有近似关系。

对 $p \ln p$ 在 $p=1$ 处做**一阶泰勒展开**：$-\ln p \approx 1 - p$

因此： $$\text{Ent}(D) = -\sum_k p_k \log_2 p_k \approx \frac{1}{\ln 2}\sum_k p_k(1 - p_k) = \frac{1}{\ln 2}\text{Gini}(D)$$

**基尼指数是信息熵的一阶近似**——两者在大多数情况下选出的最优划分属性**几乎相同**。

**CART 偏爱基尼指数的原因**：

1. **计算更快**——只涉及乘法和加法，不用算对数（$\log$ 计算昂贵）
2. **效果差不多**——既然结果相近，那就选计算快的
3. **数值稳定**——避免 $\log 0$ 的边界问题

> 💡 工业级 GBDT、XGBoost 等都用基尼指数或类似形式，**追求训练速度**。

---

### 4. 预剪枝、后剪枝各在什么场景下用？为什么后剪枝通常更好但工业上预剪枝也常用？

**适用场景**：

|场景|推荐方法|
|---|---|
|数据量极大、训练时间敏感|预剪枝|
|数据量适中、追求泛化性能|后剪枝|
|实时模型更新|预剪枝|
|离线训练、模型质量优先|后剪枝|

**后剪枝通常更好的原因**：

- **避免预剪枝的贪心错误**——某些划分当前看没收益，后续可能有大收益
- 完整生成树后再剪，**全局视野**更好
- **欠拟合风险低**

**工业上仍常用预剪枝的原因**：

1. **训练速度**——大数据集上后剪枝的开销难以承受
2. **直接可控**——通过 `max_depth`、`min_samples_leaf` 等**超参数**直接限制树结构（这是一种预剪枝）
3. **集成学习的需要**——随机森林、GBDT 中**单棵树不需要很精**，预剪枝足够 + 集成自然抑制过拟合
4. **现代实践中**：`max_depth=3~8`、`min_samples_leaf=20~100` 等参数已成默认配置

> 💡 sklearn 的 `DecisionTreeClassifier` 默认是**预剪枝控制**（通过参数），没有内置后剪枝（虽然 0.22 版本之后加入了 `ccp_alpha` 代价复杂度剪枝）。

### 5. 连续属性在一次划分后是否就不能再用？为什么？

**不是——可以再次使用，但用不同的划分点。**

**与离散属性的对比**：

- **离散属性**（如"色泽"）：一次划分后，所有该属性取值已被穷尽（青绿/乌黑/浅白各成一支），后续节点没法再划分
- **连续属性**（如"密度"）：取值是无限的，一次划分（如 密度 ≤ 0.381）只用了一个划分点——后续节点仍可在 [0, 0.381] 或 (0.381, 1] 内**选新的划分点**继续划分

**例子**：

```
密度 ≤ 0.381?
├── 是 → 密度 ≤ 0.245?     ← 连续属性继续被使用
│         ├── 是 → ...
│         └── 否 → ...
└── 否 → 密度 ≤ 0.708?     ← 连续属性继续被使用
          ├── 是 → ...
          └── 否 → ...
```

> 💡 这也是为什么连续属性可以让树长得很深——它有无穷多个划分点可选。

### 6. 一个只有 100 个样本的数据集，决策树长到 50 层——很可能发生了什么？怎么办？

**很可能发生的问题：严重过拟合 ⚠️**

**原因分析**：

- 100 个样本理论上最多需要 $\log_2 100 \approx 7$ 层就能完全区分
- 长到 50 层意味着树在**强行拟合每个样本**（甚至噪声）
- 训练精度可能 100%，但测试精度会很差

**解决方法（按优先级）**：

**① 预剪枝（最直接）**

- 限制 `max_depth`（如 5~10）
- 限制 `min_samples_split`（如 ≥ 10）
- 限制 `min_samples_leaf`（如 ≥ 5）
- 限制 `max_leaf_nodes`

**② 后剪枝**

- 用代价复杂度剪枝（CCP，sklearn 的 `ccp_alpha`）
- 用验证集自底向上剪

**③ 集成学习**

- 用**随机森林**：多棵树投票，单棵不需要太精
- 用 **GBDT**：浅树（深度 3~6）累加

**④ 数据角度**

- 检查是否有**噪声标签**
- 考虑**数据扩充**（小数据集本身就难训）
- 用**交叉验证**评估真实泛化性能

**⑤ 换模型**

- 数据量小（100 样本）的话，决策树本身就不是好选择
- 试试**朴素贝叶斯、KNN、SVM**（小数据更鲁棒）

> 💡 经验法则：**叶节点样本数应 ≥ 样本总数的 1%~5%**——100 样本的话，每个叶节点至少 1~5 个样本，树深度通常不超过 5~7 层。

### 7. 为什么单棵决策树容易过拟合，但随机森林却很稳定？（第 8 章伏笔）

**单棵决策树过拟合的原因**：

- **高方差**——训练数据微小变化会导致树结构大变（不同划分点、不同分裂顺序）
- **贪心算法**——每步选局部最优，可能整体次优
- **可以无限分裂**——若不剪枝，可完美拟合训练集（每个叶节点 1 个样本）

**随机森林稳定的原因（双重随机）**：

**① 样本随机（Bootstrap 采样）**

- 每棵树用**有放回采样**得到不同的训练子集
- 每棵树看到的数据不同 → 学到的模型不同 → **多样性**

**② 特征随机**

- 每个节点划分时，只从**随机选取的一部分特征**中选最优（如 $\sqrt{d}$ 个）
- 进一步增加多样性，避免所有树都依赖少数强特征

**③ 投票/平均集成**

- 分类：多数投票；回归：取平均
- **方差降低**：假设 T 棵树的预测方差为 $\sigma^2$、两两相关性为 $\rho$，集成方差为： $$\text{Var}_{\text{ensemble}} = \rho\sigma^2 + \frac{1-\rho}{T}\sigma^2$$
- T 越大、$\rho$ 越小（多样性越好），方差越小

**直观类比**：

- 单棵树 = 一个**自信但可能偏激**的专家
- 随机森林 = 一个**多元专家委员会**——个体可能有偏差，但**集体决策更鲁棒**

**关键洞察 ⭐**：

- 单棵树**偏差低、方差高** → 通过 Bagging **降方差**
- 这正是 Bagging 的核心机制：**用多个高方差低偏差的强学习器集成**
- Boosting 反过来：**用多个高偏差低方差的弱学习器集成降偏差**

> 💡 这是第 2 章（偏差-方差分解）+ 第 4 章（决策树）+ 第 8 章（集成学习）的**三位一体**——西瓜书最重要的理论主线之一。
