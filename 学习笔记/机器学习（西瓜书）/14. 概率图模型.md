
## 1. 隐马尔可夫模型

### 概率图模型

- 有向图模型（**贝叶斯网**）：使用**有向无环图**表示变量间的依赖关系
- 无向图模型（**马尔可夫网**）：使用**无向图**表示变量间的相关关系

### 隐马尔可夫模型（HMM）

>结构最简单的**动态贝叶斯网**，主要用于**时序数据建模**，在**语音识别**，**自然语言处理**等领域有广泛应用

#### 两类变量

- **状态变量 $y_i$（隐变量）**：第 $i$ 时刻的系统状态，不可被观测
- **观测变量 $x_i$**：第 $i$ 时刻的观测值

#### 两种假设

- **马尔可夫假设**（齐次马尔可夫性）：**当前状态只依赖于前一个状态**，与更早的状态无关： $$P(y_t | y_{t-1}, y_{t-2}, ...) = P(y_t | y_{t-1})$$
- **观测独立性假设**：**当前观测只依赖于当前状态**： $$P(x_t | y_t, y_{t-1}, ..., x_{t-1}, ...) = P(x_t | y_t)$$

#### 三组参数

- **状态转移概率 $A$**：模型在各个状态间转换的概率
- **输出观测概率 $B$**：模型根据当前状态获得各个观测值的概率
- **初始状态概率 $\pi$**：模型在初始时刻各状态出现的概率

#### 观测序列

1. **选择初始状态**：设置时间步 $t = 1$，并根据初始状态概率向量 $\boldsymbol{\pi}$ 抽样选择初始状态 $y_1$。
2. **生成观测变量**：根据当前所处的状态 $y_t$ 和输出观测概率矩阵 $\mathbf{B}$，抽样选择并确定观测变量的取值 $x_t$。
3. **转移模型状态**：根据当前所处的状态 $y_t$ 和状态转移矩阵 $\mathbf{A}$，发生状态转移以确定下一个时间步的模型状态 $y_{t+1}$。
4. **循环或终止判断**：检查时间步是否满足 $t < n$；若满足则设置 $t = t + 1$ 并转到步骤 2 继续执行，否则停止运行。

## 2. 马尔可夫随机场（MRF）

>**无向图模型**，典型的马尔可夫网

### 联合概率

$$P(x) = \frac{1}{Z}\prod_{Q} \psi_Q(x_Q)$$

- **团**：图中两两相连的节点子集
- **极大团**：不能再加入任何节点的团
- $\psi_Q$为与团 $Q$ 对应的**势函数**，用于对团 $Q$ 中的变量关系进行建模

### 条件独立性

如果变量之间的信息流动在图中被“阻断”了，那么它们就是条件独立的

- **全局马尔可夫性**：若变量子集 $Z$ 分离 $X$ 和 $Y$，则 $X \perp Y | Z$
- **局部马尔可夫性**：给定一个节点的邻接变量，该变量条件独立于其他变量
- **成对马尔可夫性**：给定所有其他变量，两个非邻接变量条件独立

## 3. 条件随机场（CRF）

>**判别式**  **无向图模型**，对条件分布进行建模

令 $G = \langle V,E \rangle$ 表示结点与标记变量 $\mathbf{y}$ 中元素一一对应的无向图，其中 $y_v$ 表示与结点 $v$ 对应的标记变量，$n(v)$ 表示结点 $v$ 的邻接结点。若图 $G$ 的每个变量 $y_v$ 都满足局部马尔可夫性时
$$P(y_v \mid \mathbf{x}, \mathbf{y}_{V \setminus \{v\}}) = P(y_v \mid \mathbf{x}, \mathbf{y}_{n(v)})$$
则 $(\mathbf{y}, \mathbf{x})$ 构成一个**条件随机场**

### 条件概率

$$P(y|x) = \frac{1}{Z(x)}\exp\left(\sum_{j,i} \lambda_j t_j(y_{i-1}, y_i, x, i) + \sum_{k,i}\mu_k s_k(y_i, x, i)\right)$$

- **转移特征 $t_j$**：刻画相邻标记变量之间的相关关系以及观测序列对它们的影响
- **状态特征 $s_k$**：刻画观测序列对当前标记变量的影响

## 4. 学习与推断

>**推断**：利用已知变量推测未知变量的分布

### 概率分布

- **条件概率分布**：$P(\mathbf{x}_F \mid \mathbf{x}_E) = \frac{P(\mathbf{x}_E, \mathbf{x}_F)}{P(\mathbf{x}_E)} = \frac{P(\mathbf{x}_E, \mathbf{x}_F)}{\sum_{\mathbf{x}_F} P(\mathbf{x}_E, \mathbf{x}_F)}$
- **边际概率分布**：$P(\mathbf{x}_E) = \sum_{\mathbf{x}_F} P(\mathbf{x}_E, \mathbf{x}_F)$

### 推断方法

- **精确推断**：计算出目标变量的边际分布或条件分布的精确值
- **近似推断**：在较低的时间复杂度下获取原问题的近似解

### 精确推断

- **变量消去**：利用乘法对加法的分配律，把多个变量的积的求和转为对部分变量交替进行求积与求和的问题
- **信念传播**：将变量消去法中的求和操作看作一个消息传递的过程

## 5. 近似推断

### 两类

- 采样：通过使用**随机化方法**完成近似
- 使用**确定性近似**完成近似推断

### MCMC (马尔可夫链蒙特卡洛)采样

1. **构造马尔可夫链**：设法构造一条马尔可夫链，使其收敛至平稳分布恰好为待估计参数的后验分布。
2. **转移概率构造**：设计并确定马尔可夫链的转移概率（此处的构造至关重要，不同的构造方法将产生不同的 MCMC 算法）。
3. **产生后验样本**：通过运行这条马尔可夫链，连续采样来产生一系列符合该后验分布的样本。
4. **进行参数估计**：基于这些产生出来的符合后验分布的样本，进行最终的参数估计计算。

### 变分推断

>使用一个已知简单分布去逼近需推断的复杂分布

## 6. 话题模型

>**生成式**  **有向图模型**，主要用于处理**离散型数据**（如文本）

- 词：待处理数据的基本离散单元
- 文档：待处理的数据对象，由一组词组成，这些词在文档中是不计顺序的
- 话题：一个概念，具体表示为一系列相关的词，以及它们在该概念下出现的概率

### 隐狄利克雷分配模型(LDA )

1. **采样文档的话题分布**：根据参数为 $\boldsymbol{\alpha}$ 的狄利克雷分布，随机采样一个用来表示文档 $t$ 中所包含的每个话题比例的向量 $\boldsymbol{\Theta}_t$。
2. **进行词级别的话题指派**：对于文档中的第 $n$ 个词，根据上一步采样得到的话题分布 $\boldsymbol{\Theta}_t$ 进行话题指派，从而确定该词所对应的话题 $z_{t,n}$。
3. **根据话题采样生成词**：根据上一步指派的话题所对应的词频分布 $\boldsymbol{\beta}_k$，进行随机采样以最终生成具体的词。
4. **循环生成整篇文档**：重复执行步骤 2 和步骤 3 共 $N$ 次，以此按顺序逐个生成文档中的全部 $N$ 个词。
