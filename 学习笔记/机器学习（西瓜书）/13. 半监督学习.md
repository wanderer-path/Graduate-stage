
## 1. 未标记样本

>**半监督学习**：让学习器不依赖外界交互，自动地利用未标记样本来提升学习性能

- **有标记数据** $D_l$：少量，标注昂贵
- **无标记数据** $D_u$：大量，容易获得
- **主动学习**：有标记 + 无标记，但**主动查询**标注最有价值的样本

### 两种假设

>将未标记样本所揭示的数据分布信息与类别标记相联系。本质“**相似的样本拥有相似的输出**”

- **聚类假设**：假设数据存在簇结构，同一个簇的样本属于用一个类别
- **流形假设**：假设数据分布在一个流行结构上，邻近的样本拥有相似的输出值

### 两种半监督学习类型

- **纯半监督学习**：训练用的未标记数据不是待预测数据，泛化到**未见过的新样本**
- **直推学习**：训练用的未标记数据就是待预测数据，只预测**训练时见过的那些无标记样本**

## 2. 生成式方法

>假设所有数据（无论是否有标记）都是由一个潜在的模型“生成”的，将未标记数据的标记看作是隐变量，使用EM算法

1. **初始参数估计**：先利用有标签的数据，计算出各个类别的初始模型参数
2. **计算属于各成分概率 (E步)**：利用当前的模型参数去测试所有**没有标签**的数据，计算出每个无标签样本属于各个类别的概率
3. **更新模型参数 (M步)**：将有标签数据的“真实标签”与无标签数据的“预估概率”结合在一起，重新计算并更新所有类别的模型参数
4. **循环迭代至收敛**：重复执行步骤 2 和步骤 3，直到模型参数不再发生明显变化，即可用最终的模型对新样本进行分类预测

- 模型必须准确，即假设的生成式模型必须与真实数据分布吻合
- 如果模型假设错误，则会降低泛化性能

## 3. 半监督SVM（S3VM）

>找到将两类有标记样本分开，且穿过数据**低密度区域**的划分超平面

### TSVM算法

>对未标记样本进行标记指派，然后在所有结果中，寻求一个所有样本上间隔最大化的划分超平面

1. **学习初始 SVM**：先利用有标记样本学得一个初始 SVM，即忽略关于未标记数据与伪标记的项及约束
2. **预分配伪标记**：利用这个初始 SVM 对未标记数据进行标记指派，即将 SVM 预测的结果作为“伪标记”赋予未标记样本
3. **求解标准 SVM 并设置小惩罚值**：将伪标记代入后求解新的划分超平面和松弛向量。注意到此时伪标记可能不准确，因此需将未标记样本的折中参数 $C_u$ 设置为比有标记样本参数 $C_l$ 小的值，使有标记样本起作用更大
4. **交换异类错误标记**：找出两个标记指派为异类且很可能发生错误的未标记样本，交换它们的标记，并重新求解出更新后的划分超平面和松弛向量
5. **增大惩罚值并循环迭代**：标记指派调整完成后，逐渐增大 $C_u$ 以提高未标记样本对优化目标的影响，并进行下一轮标记指派调整，直至 $C_u = C_l$ 为止

## 4. 图半监督学习

>将数据集映射为一张图，数据集中每个样本对应图中的一个节点，若两个样本之间的相似度很高，则对应节点间存在一条边

1. **构建相似度矩阵**：基于全体样本和构图参数 $\sigma$ 计算样本间的相似度，进而得到邻接边集矩阵 $\mathbf{W}$。
2. **构建标记传播矩阵**：基于矩阵 $\mathbf{W}$ 及其度矩阵 $\mathbf{D}$ 进行双边归一化，构建出标记传播矩阵 $\mathbf{S} = \mathbf{D}^{-\frac{1}{2}}\mathbf{W}\mathbf{D}^{-\frac{1}{2}}$。
3. **初始化标记矩阵**：根据已知标签的指示情况，初始化非负标记矩阵 $\mathbf{F}(0)$，使其前 $l$ 行对应有标记样本的真实标记向量。
4. **迭代传播与信息折中**：在每次迭代中，将当前的标记矩阵通过 $\mathbf{S}$ 进行图上传播，并引入初始标记矩阵 $\mathbf{Y}$ 进行加权折中以保留原始监督信息。
5. **计算收敛解并指派标记**：重复执行步骤 4 直至迭代收敛至最终状态 $\mathbf{F}^*$（或直接求解闭式解），最后遍历未标记样本，将其指派给 $\mathbf{F}^*$ 中对应行概率最大的类别。

- $\mathbf{F}_{ij}$，代表的是：**第 $i$ 个样本，属于第 $j$ 个类别的“可能性（或置信度）”**
- 边的强度正比于样本之间的相似度
- 存储开销大

## 5. 基于分歧的方法

>利用多视图数据的差异性训练多个学习器，让它们挑选自己最有把握的未标记样本打上伪标签后“互相教学”

### 协同训练

1. **初始训练**：在每个特征视图上，首先基于现有的**有标记样本**分别训练出一个分类器
2. **预估与打标**：让每个分类器分别去预测未标记数据，挑选出自己“最有把握的”未标记样本赋予伪标记
3. **交换数据与更新**：将这些带有伪标记的样本作为**新增的有标记样本**，提供给**另一个**分类器用于训练更新
4. **迭代终止**：这个“互相学习、共同进步”的过程不断迭代进行，直到**两个分类器都不再发生变化**，或**达到预先设定的迭代轮数**为止

- 利用多视图的“**相容互补性**”
- 若两个视图**充分且条件独立**，协同训练能显著提升性能
- 不同视图/不同算法/不同数据采样/不同参数设置都可以产生有分歧的学习器

## 6. 半监督聚类

>在传统的无监督聚类过程中，巧妙引入少量的“必连/勿连”关系约束或有标记样本作为“向导”来指导聚类结果

### 两种监督信息

- **“必连”与“勿连”约束**
	- “必连”约束：样本必属于同一个簇
	- “勿连”约束：样本必不属于同一个簇
- **少量的有标记信息**

### 约束 $k$ 均值算法

1. **初始均值向量选取**：从样本集 $D$ 中随机选取 $k$ 个样本作为初始均值向量。
2. **初始化聚类簇并遍历样本**：初始化聚类簇，随后开始遍历数据集中的每一个样本，并计算该样本与各个均值向量的距离。
3. **寻找最近簇并检测约束**：基于未尝试的簇集合，找出与当前样本距离最近的簇，并检测将该样本划入该聚类簇中是否会违背“必连”约束集合 $\mathcal{M}$ 与“勿连”约束集合 $\mathcal{C}$ 中的约束。
4. **受限划分与冲突调整**：若不违背约束，则将样本划入该簇并标记划入成功；若违背约束，则将该簇从当前样本的候选簇集合中剔除并尝试次近的簇（若所有簇都违背约束则退出并返回错误提示）。
5. **更新均值向量并循环迭代**：当所有样本分配完成后，重新计算每个簇的均值向量，重复执行步骤 2 至步骤 4，直到均值向量均未更新为止。

### 约束种子 $k$ 均值算法

1. **种子初始化均值中心**：利用给定的少量有标记样本（种子集 $\mathcal{S}$），分别计算每个类别种子样本的平均值，作为各个聚类簇的初始均值向量。
2. **强制划分种子样本**：初始化聚类簇，随后将所有已知的种子样本**直接强制归入**其对应的聚类簇中，在后续迭代中不改变它们的簇隶属关系。
3. **分配普通未标记样本**：遍历剩余的普通未标记样本，计算它们与各个均值向量的距离，并将其划分到距离最近的相应聚类簇中。
4. **更新均值向量**：当所有样本（包括种子和未标记样本）分配完毕后，重新计算每个簇中所有样本的均值，以此更新均值向量。
5. **循环迭代至收敛**：重复执行步骤 2 至步骤 4，直到均值向量均未发生更新为止。
