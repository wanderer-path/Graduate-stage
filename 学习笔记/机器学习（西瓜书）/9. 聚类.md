> 通过无标记训练样本学习数据内在性质及规律

- **簇**：聚类将数据集的样本划分为若干个通常是不相交的子集

## 3. 距离计算

距离度量 $\text{dist}(x_i, x_j)$ 需满足的**基本性质**：

1. **非负性**：$\text{dist}(x_i, x_j) \geq 0$
2. **同一性**：$\text{dist}(x_i, x_j) = 0 \Leftrightarrow x_i = x_j$
3. **对称性**：$\text{dist}(x_i, x_j) = \text{dist}(x_j, x_i)$
4. **直递性**：$\text{dist}(x_i, x_j) \leq \text{dist}(x_i, x_k) + \text{dist}(x_k, x_j)$

### 闵可夫斯基距离
 $$\text{dist}_{mk}(x_i, x_j) = \left(\sum_{u=1}^{n}|x_{iu} - x_{ju}|^p\right)^{1/p}$$
- $p = 2$：欧式距离
- $p = 1$：曼哈顿距离
- $p \to \infty$：切比雪夫距离

### 属性类型

- 有序属性：使用闵可夫斯基距离
- 无序属性：VDM
- 混合属性：闵可夫斯基 + VDM 

### 非度量属性

不满足直递性的距离

- 人马像人
- 人马像马
- 人与马不相像

## 4. 原型聚类

>假设聚类结构可以通过一组“原型”（如中心点、概率分布）来刻画，通过**迭代优化样本到这些原型的距离或隶属度**来实现划分

### $k$ 均值算法（K-means）

>通过不断**迭代计算样本到各个簇中心的距离**，并把样本分给最近的中心，直到各簇的中心点不再变动为止

**输入：** 样本集 $D = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_m\}$;
&emsp;&emsp;&emsp;聚类簇数 $k$.

**过程：**
1: 从 $D$ 中随机选择 $k$ 个样本作为初始均值向量 $\{\boldsymbol{\mu}_1, \boldsymbol{\mu}_2, \dots, \boldsymbol{\mu}_k\}$
2: **repeat**
3: &emsp;&emsp;令 $C_i = \varnothing \ (1 \leqslant i \leqslant k)$
4: &emsp;&emsp;**for** $j = 1, 2, \dots, m$ **do**
5: &emsp;&emsp;&emsp;&emsp;计算样本 $\mathbf{x}_j$ 与各均值向量 $\boldsymbol{\mu}_i \ (1 \leqslant i \leqslant k)$ 的距离：$d_{ji} = \|\mathbf{x}_j - \boldsymbol{\mu}_i\|_2$;
6: &emsp;&emsp;&emsp;&emsp;根据距离最近的均值向量确定 $\mathbf{x}_j$ 的簇标记：$\lambda_j = \arg\min_{i \in \{1, 2, \dots, k\}} d_{ji}$;
7: &emsp;&emsp;&emsp;&emsp;将样本 $\mathbf{x}_j$ 划入相应的簇：$C_{\lambda_j} = C_{\lambda_j} \cup \{\mathbf{x}_j\}$;
8: &emsp;&emsp;**end for**
9: &emsp;&emsp;**for** $i = 1, 2, \dots, k$ **do**
10: &emsp;&emsp;&emsp;&emsp;计算新均值向量：$\boldsymbol{\mu}_i' = \frac{1}{|C_i|} \sum_{\mathbf{x} \in C_i} \mathbf{x}$;
11: &emsp;&emsp;&emsp;&emsp;**if** $\boldsymbol{\mu}_i' \neq \boldsymbol{\mu}_i$ **then**
12: &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;将当前均值向量 $\boldsymbol{\mu}_i$ 更新为 $\boldsymbol{\mu}_i'$
13: &emsp;&emsp;&emsp;&emsp;**else**
14: &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;保持当前均值向量不变
15: &emsp;&emsp;&emsp;&emsp;**end if**
16: &emsp;&emsp;**end for**
17: **until** 当前均值向量均未更新

**输出：** 簇划分 $\mathcal{C} = \{C_1, C_2, \dots, C_k\}$

### 学习向量量化（LVQ）

>利用**带标签的监督信息**来辅助聚类，当随机样本与最近的原型向量同类时就将其“拉近”，异类时则“推远”

**输入：** 样本集 $D = \{(\mathbf{x}_1, y_1), (\mathbf{x}_2, y_2), \dots, (\mathbf{x}_m, y_m)\}$;
&emsp;&emsp;&emsp;原型向量个数 $q$, 各原型向量预设的类别标记 $\{t_1, t_2, \dots, t_q\}$;
&emsp;&emsp;&emsp;学习率 $\eta \in (0, 1)$.

**过程：**
1: 初始化一组原型向量 $\{\mathbf{p}_1, \mathbf{p}_2, \dots, \mathbf{p}_q\}$
2: **repeat**
3: &emsp;&emsp;从样本集 $D$ 随机选取样本 $(\mathbf{x}_j, y_j)$;
4: &emsp;&emsp;计算样本 $\mathbf{x}_j$ 与 $\mathbf{p}_i \ (1 \leqslant i \leqslant q)$ 的距离：$d_{ji} = \|\mathbf{x}_j - \mathbf{p}_i\|_2$;
5: &emsp;&emsp;找出与 $\mathbf{x}_j$ 距离最近的原型向量 $\mathbf{p}_{i^*}$, $i^* = \arg\min_{i \in \{1, 2, \dots, q\}} d_{ji}$;
6: &emsp;&emsp;**if** $y_j = t_{i^*}$ **then**
7: &emsp;&emsp;&emsp;&emsp;$\mathbf{p}' = \mathbf{p}_{i^*} + \eta \cdot (\mathbf{x}_j - \mathbf{p}_{i^*})$
8: &emsp;&emsp;**else**
9: &emsp;&emsp;&emsp;&emsp;$\mathbf{p}' = \mathbf{p}_{i^*} - \eta \cdot (\mathbf{x}_j - \mathbf{p}_{i^*})$
10: &emsp;&emsp;**end if**
11: &emsp;&emsp;将原型向量 $\mathbf{p}_{i^*}$ 更新为 $\mathbf{p}'$
12: **until** 满足停止条件

**输出：** 原型向量 $\{\mathbf{p}_1, \mathbf{p}_2, \dots, \mathbf{p}_q\}$

### 高斯混合聚类

>用多个**高斯概率分布**的组合来描述数据分布，认为**每个样本都有一定的概率属于任何一个簇**，通过概率计算来实现**软划分**

**输入：** 样本集 $D = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_m\}$;
&emsp;&emsp;&emsp;高斯混合成分个数 $k$.

**过程：**
1: 初始化高斯混合分布的模型参数 $\{(\alpha_i, \boldsymbol{\mu}_i, \mathbf{\Sigma}_i) \mid 1 \leqslant i \leqslant k\}$
2: **repeat**
3: &emsp;&emsp;**for** $j = 1, 2, \dots, m$ **do**
4: &emsp;&emsp;&emsp;&emsp;根据式(9.30)计算样本 $\mathbf{x}_j$ 由各混合成分生成的后验概率，即 $\gamma_{ji} = p_M(z_j = i \mid \mathbf{x}_j) \ (1 \leqslant i \leqslant k)$
5: &emsp;&emsp;**end for**
6: &emsp;&emsp;**for** $i = 1, 2, \dots, k$ **do**
7: &emsp;&emsp;&emsp;&emsp;计算新均值向量：$\boldsymbol{\mu}_i' = \frac{\sum_{j=1}^m \gamma_{ji} \mathbf{x}_j}{\sum_{j=1}^m \gamma_{ji}}$;
8: &emsp;&emsp;&emsp;&emsp;计算新协方差矩阵：$\mathbf{\Sigma}_i' = \frac{\sum_{j=1}^m \gamma_{ji} (\mathbf{x}_j - \boldsymbol{\mu}_i')(\mathbf{x}_j - \boldsymbol{\mu}_i')^{\mathrm{T}}}{\sum_{j=1}^m \gamma_{ji}}$;
9: &emsp;&emsp;&emsp;&emsp;计算新混合系数：$\alpha_i' = \frac{\sum_{j=1}^m \gamma_{ji}}{m}$;
10: &emsp;&emsp;**end for**
11: &emsp;&emsp;将模型参数 $\{(\alpha_i, \boldsymbol{\mu}_i, \mathbf{\Sigma}_i) \mid 1 \leqslant i \leqslant k\}$ 更新为 $\{(\alpha_i', \boldsymbol{\mu}_i', \mathbf{\Sigma}_i') \mid 1 \leqslant i \leqslant k\}$
12: **until** 满足停止条件
13: 令 $C_i = \varnothing \ (1 \leqslant i \leqslant k)$
14: **for** $j = 1, 2, \dots, m$ **do**
15: &emsp;&emsp;根据式(9.31)确定 $\mathbf{x}_j$ 的簇标记 $\lambda_j$;
16: &emsp;&emsp;将 $\mathbf{x}_j$ 划入相应的簇：$C_{\lambda_j} = C_{\lambda_j} \cup \{\mathbf{x}_j\}$
17: **end for**

**输出：** 簇划分 $\mathcal{C} = \{C_1, C_2, \dots, C_k\}$

## 5. 密度聚类

>从样本的可达性出发，通过**寻找被低密度区域隔开的高密度区域**来发现任意形状的簇，并能天然识别噪声点

### DBSCAN算法

>依据“物以类聚，人以群分”的密度连通性，只要一个区域的样本足够稠密就不断向外扩展，从而发现任意形状的簇并天然过滤噪声

**输入：** 样本集 $D = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_m\}$;
&emsp;&emsp;&emsp;邻域参数 $(\epsilon, MinPts)$.

**过程：**
1: 初始化核心对象集合：$\Omega = \varnothing$
2: **for** $j = 1, 2, \dots, m$ **do**
3: &emsp;&emsp;确定样本 $\mathbf{x}_j$ 的 $\epsilon$-邻域 $N_{\epsilon}(\mathbf{x}_j)$;
4: &emsp;&emsp;**if** $|N_{\epsilon}(\mathbf{x}_j)| \geqslant MinPts$ **then**
5: &emsp;&emsp;&emsp;&emsp;将样本 $\mathbf{x}_j$ 加入核心对象集合：$\Omega = \Omega \cup \{\mathbf{x}_j\}$
6: &emsp;&emsp;**end if**
7: **end for**
8: 初始化聚类簇数：$k = 0$
9: 初始化未访问样本集合：$\Gamma = D$
10: **while** $\Omega \neq \varnothing$ **do**
11: &emsp;&emsp;记录当前未访问样本集合：$\Gamma_{\mathrm{old}} = \Gamma$;
12: &emsp;&emsp;随机选取一个核心对象 $\mathbf{o} \in \Omega$, 初始化队列 $Q = \langle \mathbf{o} \rangle$;
13: &emsp;&emsp;$\Gamma = \Gamma \setminus \{\mathbf{o}\}$;
14: &emsp;&emsp;**while** $Q \neq \varnothing$ **do**
15: &emsp;&emsp;&emsp;&emsp;取出队列 $Q$ 中的首个样本 $\mathbf{q}$;
16: &emsp;&emsp;&emsp;&emsp;**if** $|N_{\epsilon}(\mathbf{q})| \geqslant MinPts$ **then**
17: &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;令 $\Delta = N_{\epsilon}(\mathbf{q}) \cap \Gamma$;
18: &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;将 $\Delta$ 中的样本加入队列 $Q$;
19: &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;$\Gamma = \Gamma \setminus \Delta$;
20: &emsp;&emsp;&emsp;&emsp;**end if**
21: &emsp;&emsp;**end while**
22: &emsp;&emsp;$k = k + 1$, 生成聚类簇 $C_k = \Gamma_{\mathrm{old}} \setminus \Gamma$;
23: &emsp;&emsp;$\Omega = \Omega \setminus C_k$
24: **end while**

**输出：** 簇划分 $\mathcal{C} = \{C_1, C_2, \dots, C_k\}$

## 6. 层次聚类

>在不同粒度上对数据集进行划分，通过**自底向上逐层合并最近的簇、或自顶向下逐层分裂最远的簇**来构建树状的聚类结构
### AGNES算法

>采用**自底向上**的策略，开始时把每个样本都当成一个独立的簇，然后每次把距离最近的两个簇合并，直到达到目标簇数

**输入：** 样本集 $D = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_m\}$;
&emsp;&emsp;&emsp;聚类簇距离度量函数 $d$;
&emsp;&emsp;&emsp;聚类簇数 $k$.

**过程：**
1: **for** $j = 1, 2, \dots, m$ **do**
2: &emsp;&emsp;$C_j = \{\mathbf{x}_j\}$
3: **end for**
4: **for** $i = 1, 2, \dots, m$ **do**
5: &emsp;&emsp;**for** $j = 1, 2, \dots, m$ **do**
6: &emsp;&emsp;&emsp;&emsp;$M(i, j) = d(C_i, C_j)$;
7: &emsp;&emsp;&emsp;&emsp;$M(j, i) = M(i, j)$
8: &emsp;&emsp;**end for**
9: **end for**
10: 设置当前聚类簇个数：$q = m$;
11: **while** $q > k$ **do**
12: &emsp;&emsp;找出距离最近的两个聚类簇 $C_{i^*}$ 和 $C_{j^*}$：$(i^*, j^*) = \arg\min_{i \neq j} M(i, j)$;
13: &emsp;&emsp;合并 $C_{i^*}$ 和 $C_{j^*}$：$C_{i^*} = C_{i^*} \cup C_{j^*}$;
14: &emsp;&emsp;**for** $j = j^* + 1, j^* + 2, \dots, q$ **do** （将聚类簇编号重排）
15: &emsp;&emsp;&emsp;&emsp;将聚类簇 $C_j$ 重命名为 $C_{j-1}$
16: &emsp;&emsp;**end for**
17: &emsp;&emsp;删除距离矩阵 $M$ 的第 $j^*$ 行与第 $j^*$ 列;
18: &emsp;&emsp;$q = q - 1$;
19: &emsp;&emsp;**for** $j = 1, 2, \dots, q$ **do** （更新距离矩阵）
20: &emsp;&emsp;&emsp;&emsp;$M(i^*, j) = d(C_{i^*}, C_j)$;
21: &emsp;&emsp;&emsp;&emsp;$M(j, i^*) = M(i^*, j)$
22: &emsp;&emsp;**end for**
23: **end while**

**输出：** 簇划分 $\mathcal{C} = \{C_1, C_2, \dots, C_k\}$
