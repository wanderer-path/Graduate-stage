
## 1. 任务与奖赏

- 学习的目的：找到能长期累积奖赏最大化的策略
- 延迟标记信息

### 马尔可夫决策过程（MDP）

1. **确定状态空间与动作空间**：机器处于环境 $E$ 中，状态空间为 $X$（其中每个状态 $x \in X$ 是机器感知到的环境描述），机器能采取的动作构成了动作空间 $A$
2. **界定状态转移概率函数**：若某个动作 $a \in A$ 作用在当前状态 $x$ 上，则潜在的转移函数 $P$ 将使得环境从当前状态按某种概率转移到另一个状态
3. **界定奖赏反馈函数**：在转移到另一个状态的同时，环境会根据潜在的“奖赏”（reward）函数 $R$ 反馈给机器一个奖赏_
4. **构建强化学习任务四元组**：综合状态空间、动作空间、转移函数和奖赏函数，强化学习任务最终对应并形式化为一个统一的四元组：$$E = \langle X, A, P, R \rangle$$

## 2. $K$-摇臂赌博机

>K个摇臂，每个摇臂以一定概率吐出金币，赌徒不知道概率，马努表是通过一定策略最大化自己的奖赏

### 探索与利用

- **仅探索**：将所有的尝试机会平均分配给每个摇臂，最后以每个摇臂各自的平均吐币概率作为其奖赏期望的近似估计
	- 失去很多选择最有摇臂的机会
- **仅利用**：按下目前最优的摇臂，若多个摇臂同为最优，则从中随机选取一个
	- 可能经常选择不到最优的摇臂

**探索-利用窘境**：探索与利用相互矛盾

### ε-贪心 

>基于一个概率对探索和利用进行折中。以 $\epsilon$ 概率随机探索，以 $1-\epsilon$ 概率选当前最优

**输入：**
* 摇臂数 $K$;
* 奖赏函数 $R$;
* 尝试次数 $T$;
* 探索概率 $\epsilon$.

**过程：**

1. $r = 0$;
2. $\forall i = 1, 2, \dots K : Q(i) = 0, \text{count}(i) = 0$;
3. **for** $t = 1, 2, \dots, T$ **do**
4. &emsp;&emsp;**if** $\text{rand}() < \epsilon$ **then**
5. &emsp;&emsp;&emsp;&emsp;$k = \text{从 } 1, 2, \dots, K \text{ 中以均匀分布随机选取}$
6. &emsp;&emsp;**else**
7. &emsp;&emsp;&emsp;&emsp;$k = \arg\max_i Q(i)$
8. &emsp;&emsp;**end if**
9. &emsp;&emsp;$v = R(k)$;
10. &emsp;&emsp;$r = r + v$;
11. &emsp;&emsp;$Q(k) = \frac{Q(k) \times \text{count}(k) + v}{\text{count}(k) + 1}$;
12. &emsp;&emsp;$\text{count}(k) = \text{count}(k) + 1$;
13. **end for**

**输出：**
* 累积奖赏 $r$

### Softmax

>基于当前已知的摇臂平均奖赏来对探索和利用进行折中

### Softmax 算法

**输入：**
* 摇臂数 $K$;
* 奖赏函数 $R$;
* 尝试次数 $T$;
* 温度参数 $\tau$.

**过程：**

1. $r = 0$;
2. $\forall i = 1, 2, \dots K : Q(i) = 0, \text{count}(i) = 0$;
3. **for** $t = 1, 2, \dots, T$ **do**
4. &emsp;&emsp;$k =$ 从 $1, 2, \dots, K$ 中根据$P(k) = \frac{e^{\frac{Q(k)}{\tau}}}{\sum_{i=1}^{K} e^{\frac{Q(i)}{\tau}}}$ 随机选取;
5. &emsp;&emsp;$v = R(k)$;
6. &emsp;&emsp;$r = r + v$;
7. &emsp;&emsp;$Q(k) = \frac{Q(k) \times \text{count}(k) + v}{\text{count}(k) + 1}$;
8. &emsp;&emsp;$\text{count}(k) = \text{count}(k) + 1$;
9. **end for**

**输出：**
* 累积奖赏 $r$

- $\tau > 0$ 称为“**温度**”，$\tau$ 越小则平均奖赏高的摇臂被选取得概率越高

## 3. 有模型学习

>马尔可夫决策过程四元组$E = \langle X, A, P, R \rangle$均已知

- $\pi(x, a)$：代表**在状态 $x$ 下，选择动作 $a$ 的概率**
- $P_{x\to x'}^a$： 对于任意状态 $x, x'$ 和动作 $a$，在 $x$ 状态下执行动作 $a$ 转移到 $x'$ 状态的概率
-  $R_{x\to x'}^a$： 该状态转移（即在 $x$ 状态下执行动作 $a$ 转移到 $x'$ 状态）所带来的奖赏

### 策略评估

**状态值函数**：在策略 $\pi$ 下，从状态 $x$ 出发的期望累积奖赏
$T$  步累计奖赏：有限步
$$V_T^{\pi}(x) = \sum_{a\in A} \pi(x, a) \sum_{x'\in X} P_{x\to x'}^a \left( \frac{1}{T}R_{x\to x'}^a + \frac{T - 1}{T}V_{T-1}^{\pi}(x') \right)$$
${\gamma}$ 折扣累积奖赏：无限步
$$V_{\gamma}^{\pi}(x) = \sum_{a\in A} \pi(x, a) \sum_{x'\in X} P_{x\to x'}^a \left( R_{x\to x'}^a + \gamma V_{\gamma}^{\pi}(x') \right)$$
**状态动作值函数**：在状态 $x$ 执行动作 $a$，之后按 $\pi$ 的期望累积奖赏
$$Q_T^{\pi}(x, a) = \sum_{x'\in X} P_{x\to x'}^a \left( \frac{1}{T}R_{x\to x'}^a + \frac{T - 1}{T}V_{T-1}^{\pi}(x') \right)$$
$$Q_{\gamma}^{\pi}(x, a) = \sum_{x'\in X} P_{x\to x'}^a \left( R_{x\to x'}^a + \gamma V_{\gamma}^{\pi}(x') \right)$$

### 策略改进

将策略选择的动作改为当前最优的动作

$$V_T^*(x) = \max_{a\in A} \sum_{x'\in X} P_{x\to x'}^a \left( \frac{1}{T}R_{x\to x'}^a + \frac{T - 1}{T}V_{T-1}^*(x') \right)$$
$$V_{\gamma}^*(x) = \max_{a\in A} \sum_{x'\in X} P_{x\to x'}^a \left( R_{x\to x'}^a + \gamma V_{\gamma}^*(x') \right)$$

### 策略迭代与值迭代

- **策略迭代**：交替进行：策略评估+策略改进
- **值迭代**：直接迭代贝尔曼最优方程，求最优值函数
	- $Q_T^*(x, a) = \sum_{x'\in X} P_{x\to x'}^a \left( \frac{1}{T}R_{x\to x'}^a + \frac{T - 1}{T}V_{T-1}^*(x') \right)$
	- $Q_{\gamma}^*(x, a) = \sum_{x'\in X} P_{x\to x'}^a \left( R_{x\to x'}^a + \gamma V_{\gamma}^*(x') \right)$

## 4. 免模型学习

>学习算法不依赖于环境建模

### 蒙特卡罗强化学习

>多次采样，然后求取平均累积奖赏来作为期望累积奖赏的近似

#### 同策略蒙特卡罗强化学习算法

1. **初始化状态-动作值与策略**：将所有状态-动作对的价值估计 $Q(x,a)$ 和访问计数 $\text{count}(x,a)$ 统一初始化为 0，并将初始策略 $\pi(x,a)$ 初始化为均匀分配概率
2. **执行当前策略生成轨迹**：在环境 $E$ 中完整运行当前策略 $\pi$，生成一条包含状态、动作和奖赏的采样轨迹：$\langle x_0, a_0, r_1, x_1, a_1, r_2, \dots, x_{T-1}, a_{T-1}, r_T, x_T \rangle$
3. **计算各时间步的累积回报**：沿轨迹遍历每个时间步 $t$，计算从当前步到轨迹结束的未来平均累积回报（或折扣回报）$R$
4. **增量更新状态-动作对价值**：根据计算得到的累积回报 $R$，增量更新该状态-动作对的价值估计 $Q(x_t, a_t)$，并将其访问计数 $\text{count}(x_t, a_t)$ 加 1
5. **策略改进（$\epsilon$-贪心评估）**：对所有在轨迹中已见的状态 $x$，基于更新后的 $Q$ 值进行策略改进。以 $1-\epsilon$ 的概率选择最优动作，以 $\epsilon$ 的概率进行均匀探索，由此生成下一轮迭代的新策略 $\pi$

####  异策略蒙特卡罗强化学习算法

1. **初始化状态-动作值与策略**：将所有状态-动作对的价值估计 $Q(x,a)$ 和访问计数 $\text{count}(x,a)$ 统一初始化为 0，并将目标策略 $\pi(x,a)$ 初始化为均匀分配概率
2. **执行行为策略产生采样轨迹**：在环境 $E$ 中执行当前策略 $\pi$ 的 $\epsilon$-贪心策略（即行为策略），生成一条包含状态、动作和奖赏的采样轨迹：$\langle x_0, a_0, r_1, x_1, a_1, r_2, \dots, x_{T-1}, a_{T-1}, r_T, x_T \rangle$
3. **计算各步动作的选择概率**：针对轨迹中的每一次动作，计算其在 $\epsilon$-贪心行为策略下的发生概率 $p_i$
4. **通过重要性采样计算累积回报**：沿轨迹遍历每个时间步 $t$，利用步骤 3 计算出的概率进行**重要性采样修正**，计算出目标策略对应的未来平均累积回报 $R$
5. **增量更新价值并更新目标策略**：根据修正后的回报 $R$，增量更新状态-动作对的价值估计 $Q(x_t, a_t)$ 并将计数加 1。最后在循环结束时，将目标策略 $\pi(x)$ 严格改进为当前 $Q$ 值最大的贪心动作

### 时序差分学习

>每执行一步策略就更新一次值函数估计

#### Sarsa算法

1. **初始化值函数与策略**：将所有状态-动作对的价值估计 $Q(x,a)$ 初始化为 0，并将初始策略 $\pi(x,a)$ 初始化为均匀分配概率
2. **设定初始状态与动作**：设定当前状态为起始状态 $x = x_0$，并根据当前策略 $\pi$ 选择即将执行的初始动作 $a = \pi(x)$
3. **与环境交互获取奖赏与新状态**：在环境 $E$ 中实际执行当前的动作 $a$，观测并接收环境反馈的即时奖赏 $r$ 以及转移到的新状态 $x'$
4. **基于行为策略预选下一步动作**：根据当前带探索的行为策略 $\pi^\epsilon$，在新的状态 $x'$ 下预先挑选出**下一步准备执行的动作 $a' = \pi^\epsilon(x')$**
5. **时序差分增量更新 $Q$ 值**：利用时序差分（TD）误差，结合更新步长 $\alpha$ 和折扣因子 $\gamma$，对当前的状态-动作值函数进行增量式实时更新：$$Q(x,a) = Q(x,a) + \alpha \left( r + \gamma Q(x',a') - Q(x,a) \right)$$
6. **策略改进与状态动作更替**：将目标策略 $\pi(x)$ 改进为当前 $Q$ 值最大的贪心动作。随后，将当前的状态和动作分别替换为下一步的状态 $x'$ 和预选动作 $a'$，进入下一个时间步的循环

####  Q-learning 算法

1. **初始化值函数与策略**：将所有状态-动作对的价值估计 $Q(x,a)$ 初始化为 0，并将初始策略 $\pi(x,a)$ 初始化为均匀分配概率
2. **设定初始状态**：设定当前状态为起始状态 $x = x_0$
3. **结合探索执行动作并转移**：在当前状态 $x$ 下，执行由带有探索的策略 $\pi^\epsilon(x)$ 产生的动作，并在环境 $E$ 中观测并接收反馈的即时奖赏 $r$ 以及转移到的新状态 $x'$
4. **基于目标策略预选贪心动作**：根据当前完全贪心的目标策略 $\pi$，在新状态 $x'$ 下预先挑选出**能最大化 $Q$ 值的下一步动作 $a' = \pi(x')$**
5. **时序差分增量更新 $Q$ 值**：利用时序差分（TD）误差，结合更新步长 $\alpha$ 和折扣因子 $\gamma$，对当前的状态-动作值函数进行增量式更新： $$Q(x,a) = Q(x,a) + \alpha \left( r + \gamma Q(x',a') - Q(x,a) \right)$$
6. **策略改进与状态更替**：将目标策略 $\pi(x)$ 改进为当前 $Q$ 值最大的贪心动作。随后，将当前的状态替换为下一步的状态 $x'$，进入下一个时间步的循环
