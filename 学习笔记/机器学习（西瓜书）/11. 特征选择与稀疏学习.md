
## 1. 子集搜索与评价

**基本概念**：
- 相关特征：对当前任务有用的属性
- 无关特征：对当前任务无用的属性
- 冗余特征：信息能从别的特征推出来的属性

**目的**：
- 缓解维数灾难
- 去除不想管特征，降低学习任务难度

### 子集搜索

- **前向**：从空集出发，每轮加入一个让评价最好的特征
- **后向**：从全集出发，每轮去掉一个最没用的
- **双向**：两者结合

**ps**：基于**贪心算法**可能陷入局部最优解

### 子集评价

>衡量子集划分好坏，常用信息增益

**特征选择=特征子集搜索+子集评价**

## 2. 过滤式选择

>先用特征选择过程对初试特征进行“过滤”，再用过滤后的特征来训练模型

- **猜中近邻**：同类样本中最近邻的样本 $x_{i,nh}$
- **猜错近邻**：异类样本中最近邻的样本 $x_{i,nm}$
- **相关统计量**
$$\delta^j = \sum_i\Big(-\text{diff}(x_i^j, x_{i,nh}^j)^2 + \text{diff}(x_i^j, x_{i,nm}^j)^2\Big)$$
- 如果猜中近邻小于猜错近邻，则说明属性对区分同类与异类是有益的
- 如果猜中近邻大于猜错近邻，则说明属性对区分同类与异类是负作用

## 3. 包裹式选择

>把最终使用的学习器的性能作为为特征子集的评价标准

### LVW算法

>使用随机策略来进行子集搜索，用交叉验证估计学习器误差，并以最终分类器的误差为特征子集评价准则

**输入：** 数据集 $D$;
&emsp;&emsp;&emsp;特征集 $A$;
&emsp;&emsp;&emsp;学习算法 $\mathfrak{L}$;
&emsp;&emsp;&emsp;停止条件控制参数 $T$.

**过程：**
1: $E = \infty$;
2: $d = |A|$;
3: $A^* = A$;
4: $t = 0$;
5: **while** $t < T$ **do**
6: &emsp;&emsp;随机产生特征子集 $A'$;
7: &emsp;&emsp;$d' = |A'|$;
8: &emsp;&emsp;$E' = \mathrm{CrossValidation}(\mathfrak{L}(D^{A'}))$;
9: &emsp;&emsp;**if** $(E' < E) \lor ((E' = E) \land (d' < d))$ **then**
10: &emsp;&emsp;&emsp;&emsp;$t = 0$;
11: &emsp;&emsp;&emsp;&emsp;$E = E'$;
12: &emsp;&emsp;&emsp;&emsp;$d = d'$;
13: &emsp;&emsp;&emsp;&emsp;$A^* = A'$
14: &emsp;&emsp;**else**
15: &emsp;&emsp;&emsp;&emsp;$t = t + 1$
16: &emsp;&emsp;**end if**
17: **end while**

**输出：** 特征子集 $A^*$

## 4. 嵌入式选择与$L_1$正则化

### 嵌入式选择

>将特征选择过程与学习器训练过程融合在一起，即学习器训练过程中自动进行特征选择

### 正则化

$$\|\mathbf{w}\|_p = \left( \sum_{i=1}^d |w_i|^p \right)^{\frac{1}{p}}$$
- p=1：$L_1$（LASSO）：$\min_w \sum_i (y_i - w^\top x_i)^2 + \lambda||w||_1$
- p=2：$L_2$（岭回归）：$\min_w \sum_i (y_i - w^\top x_i)^2 + \lambda||w||_2^2$

- $L_1$范数：更容易得到稀疏解-求出的w中很多分量为0
- $L_1$正则化问题的求解使用**近端梯度下降**（PGD）

## 5. 稀疏表示与字典学习

### 稀疏表示

- 特征稀疏：矩阵中很多行或列与学习任务无关
- 表示稀疏：矩阵中存在很多的零元素，但并不是以整行或整列的方式存在

### 字典学习（稀疏编码）

>为普通稠密表达的样本找到合适的字典，将样本转化为合适的稀疏表达形式

$$\min_{B, \alpha} \sum_i |x_i - B\alpha_i|_2^2 + \lambda \sum_i |\alpha_i|_1$$

- $B$：字典（待学习的基）
- $\alpha_i$：样本 $x_i$ 的**稀疏表示**（系数大多为 0）
- **求解**：交替优化——固定 $B$ 求 $\alpha$（稀疏编码），固定 $\alpha$ 求 $B$（更新字典）
