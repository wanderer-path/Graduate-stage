# LoRA 微调原理笔记

> **范围**：经典 LoRA 的前向与反向传播、LLM 监督微调、Adapter 与显存、QLoRA，以及 AdaLoRA、rsLoRA、LoRA+、DoRA、PiSSA。只讨论原理，不涉及框架 API 和训练脚本。  
> **约定**：全文使用列向量 $x\in\mathbb R^{d_{in}\times1}$；$s=\alpha/r$ 是经典 LoRA 缩放系数。小矩阵和概率均为教学算例，不代表实际模型指标。

---

## 0. 完整机制

**LoRA 不缩小原模型，而是冻结其预训练权重，在选定的线性层增加一个可训练的低秩修正分支。**

$$
\boxed{h=Wx+\underbrace{\frac{\alpha}{r}BAx}_{\text{LoRA 修正}}}
$$

| 对象 | 含义 | 微调时发生什么 |
|---|---|---|
| $W$ | 预训练线性层权重 | 冻结，参与计算但不更新 |
| $A$、$B$ | 两个低秩适配矩阵 | 根据 Loss 的梯度更新 |
| $r$ | 低秩维度 | 决定更新容量与参数量 |
| $\alpha/r$ | 修正分支缩放系数 | 影响前向输出和梯度尺度 |

```text
训练数据 → Tokenizer → Embedding → Transformer（W + LoRA）→ Logits
                                 ↑                              ↓
                        更新各层 A、B ← 反向传播 ← Cross-Entropy Loss
```

**一切后续方法都可以从这里比较**：QLoRA 主要压缩冻结的 $W$；AdaLoRA 调整低秩容量分配；rsLoRA 修改缩放；LoRA+ 修改优化步长；DoRA 修改权重参数化；PiSSA 修改低秩初始化及冻结部分的分解。

## 1. 为什么需要 LoRA

### 1.1 全参数微调和低秩微调的区别

普通线性层的输出是 $h=Wx$。全参数微调直接修改 $W$，例如 SGD 更新为：

$$W_{new}=W-\eta\nabla_W L$$

这意味着要为大量权重计算或保存梯度，还要维护优化器状态。模型权重能装进显存，不代表可以在同样显存下对其进行全参数训练。

LoRA 不直接训练与 $W$ 一样大的增量 $\Delta W$，而限制：

$$\boxed{\Delta W=sBA,\qquad W_{effective}=W+\Delta W}$$

只要训练使 $A$ 或 $B$ 改变，$BA$ 就可能改变；**原始 $W$ 完全不动，模型的有效权重和输出仍然会改变。**

### 1.2 “低秩”限制的究竟是什么

$$BA=\sum_{k=1}^{r}B_{:,k}A_{k,:},\qquad \operatorname{rank}(BA)\le r$$

$BA$ 是最多 $r$ 个秩 1 外积之和。它的**矩阵形状与 $W$ 相同**，但各元素之间受低秩结构约束，不能像全参数微调那样自由地独立变化。被限制的是**权重增量**，不是原模型、输入或 Hidden States 的秩。

对一个 $4096\times4096$ 的线性层：

| 方案 | 可训练参数量 |
|---|---:|
| 直接训练整个 $W$ | $4096^2=16,777,216$ |
| LoRA，$r=8$ | $8\times4096+4096\times8=65,536$ |

该层可训练参数仅为原权重数量的 **0.390625%**，减少约 **256 倍**。这不是整个模型的显存下降倍数。

**为什么可能有效？** 预训练模型已经拥有通用能力，某些下游任务所需的更新可能集中在较少的方向；低秩参数化有机会表达这些变化。它是有实验支持的有效假设，**不是所有任务都只需要低秩更新的数学定理**。

## 2. LoRA 如何进行前向计算

### 2.1 A 和 B 的维度及计算顺序

设输入维度 $d_{in}$，输出维度 $d_{out}$，Rank 为 $r$：

$$
\begin{aligned}
x&\in\mathbb R^{d_{in}\times1}, &W&\in\mathbb R^{d_{out}\times d_{in}},\\
A&\in\mathbb R^{r\times d_{in}}, &B&\in\mathbb R^{d_{out}\times r}.
\end{aligned}
$$

计算从右向左：

$$x\xrightarrow{A}Ax\;(r\times1)\xrightarrow{B}BAx\;(d_{out}\times1)$$

因此 $BAx$ 与原分支 $Wx$ 同维，可以相加。

```text
                      输入 x
                     /     \
                    ↓       ↓
             W（冻结）     A（训练）：d_in → r
                    ↓       ↓
                   Wx     B（训练）：r → d_out
                    \      /
                     相加（LoRA 分支乘 s）
                              ↓
                           输出 h
```

“A 降维、B 升维”指特征映射，不是把输入无损压缩再还原。

### 2.2 用一组数字完整计算前向

令 $r=1,\alpha=1$，所以 $s=1$：

$$
W=\begin{bmatrix}1&2&0\\-1&1&1\end{bmatrix},\quad
x=\begin{bmatrix}2\\1\\-1\end{bmatrix},\quad
A=\begin{bmatrix}1&0&-1\end{bmatrix},\quad
B=\begin{bmatrix}0.5\\-1\end{bmatrix}.
$$

先计算基础分支：

$$Wx=\begin{bmatrix}4\\-2\end{bmatrix}$$

LoRA 分支：

$$Ax=1\times2+0\times1+(-1)\times(-1)=3$$
$$BAx=3\begin{bmatrix}0.5\\-1\end{bmatrix}=\begin{bmatrix}1.5\\-3\end{bmatrix}$$

最终：

$$\boxed{h=Wx+BAx=\begin{bmatrix}5.5\\-5\end{bmatrix}}$$

原来的输出是 $[4,-2]^T$，加上修正后变成 $[5.5,-5]^T$。**改变的不是冻结的 $W$，而是模型使用了额外的 $BA$。** 等价地，可以先构造 $(W+BA)$，再乘 $x$。

### 2.3 r、α 和初始化分别负责什么

- **$r$**：控制增量可达到的最大秩和可训练参数量 $r(d_{in}+d_{out})$；更大不保证更准确。
- **$\alpha$**：通过 $s=\alpha/r$ 缩放 LoRA 分支；不是学习率，也不是最终精度放大倍数。
- **初始化**：经典 LoRA 通常将 $A$ 随机初始化、$B$ 置零，使最初 $BA=0$，新增分支不会扰动预训练模型的初始输出。

为什么不把 A、B 都置零，需要看梯度公式。

## 3. Loss 如何更新 A、B

**这是 LoRA 训练的核心：前向传播得到输出和 Loss；反向传播计算梯度；优化器才真正修改 A、B。**

### 3.1 从链式法则推导梯度

写成中间变量形式：

$$z=Ax,\qquad h=Wx+sBz,\qquad g=\frac{\partial L}{\partial h}$$

$g$ 是从后续网络返回的输出梯度，不依赖使用哪一种具体损失函数。

**对 B 求导。** 对元素 $B_{ik}$，有 $\partial h_i/\partial B_{ik}=s z_k$，所以：

$$\frac{\partial L}{\partial B_{ik}}=s g_i z_k$$
$$\boxed{\nabla_B L=s\,g(Ax)^T}$$

直观地说，**B 的梯度 = 输出误差信号 × A 产生的低维特征**。

**对 A 求导。** 必须先让梯度穿过 B，回到中间变量 $z$：

$$\frac{\partial L}{\partial z}=sB^Tg$$

再利用 $z=Ax$：

$$\boxed{\nabla_A L=s(B^Tg)x^T}$$

因此，**A 的梯度 = 经 B 传回的低维误差信号 × 原始输入特征**。真实 LLM 中，各样本、各 Token 对共享参数的贡献会汇总。

### 3.2 沿用前向的数字，更新一次参数

设训练目标 $t=[5,-4]^T$。为了清楚展示求导，暂时使用平方误差（实际 LLM 通常使用 Token Cross-Entropy）：

$$L=\tfrac12\|h-t\|^2=\tfrac12(0.5^2+(-1)^2)=0.625$$
$$g=h-t=\begin{bmatrix}0.5\\-1\end{bmatrix}$$

利用 $Ax=3$：

$$\nabla_B L=\begin{bmatrix}0.5\\-1\end{bmatrix}\times3=\begin{bmatrix}1.5\\-3\end{bmatrix}$$

又因为 $B^Tg=0.5\times0.5+(-1)\times(-1)=1.25$：

$$\nabla_A L=1.25[2,1,-1]=[2.5,1.25,-1.25]$$

使用 SGD，$\eta=0.1$，基于**同一次前向/反向算出的梯度**更新：

$$
\begin{aligned}
A'&=A-0.1\nabla_A L=[0.75,-0.125,-0.875],\\
B'&=B-0.1\nabla_B L=[0.35,-0.7]^T.
\end{aligned}
$$

再次前向：

$$A'x=2.25,\quad B'A'x=[0.7875,-1.575]^T$$
$$h'=[4.7875,-3.575]^T,\qquad L'=0.112890625$$

| 项目 | 更新前 | 更新后 |
|---|---:|---:|
| 输出 $h$ | $[5.5,-5]^T$ | $[4.7875,-3.575]^T$ |
| Loss | $0.625$ | 约 $0.1129$ |
| $W$ | 不变 | 不变 |

这个例子恰好 Loss 下降；一般训练不保证每一步下降。实际常使用 AdamW，但改变的是**如何利用梯度**，而不是上述链式求导关系。

更严格地说，若 $A'=A+\delta A$、$B'=B+\delta B$，那么：

$$B'A'-BA=\delta B\,A+B\,\delta A+\delta B\,\delta A$$

可见训练 A、B **不等于**直接对完整 $W$ 执行一次普通梯度下降：低秩因子的更新会共同决定实际权重增量。

### 3.3 为什么初始 B=0 可以训练，A 却暂时不动

代入梯度式：

$$B=0\Rightarrow \nabla_A L=s(B^Tg)x^T=0$$
$$\nabla_B L=s\,g(Ax)^T\quad\text{通常非零}$$

所以初次更新通常先改变 B；B 非零之后，A 通常也开始获得非零梯度。若 $A=B=0$，两组梯度初始都为零，普通梯度下降无法启动低秩分支。

同一个教学例子若改成初始 $B=[0,0]^T$，此时 $h=Wx=[4,-2]^T$、$g=[-1,2]^T$、$Ax=3$，于是 $\nabla_B L=[-3,6]^T$、$\nabla_A L=0$，与公式完全一致。

### 3.4 冻结 W 为什么不切断反向传播

冻结 $W$ 只意味着**不更新 W，也无需为它维护参数梯度及优化器状态**；必要时仍能计算这个层的输入梯度：

$$\boxed{\frac{\partial L}{\partial x}=W^Tg+sA^TB^Tg}$$

注意 $W^Tg$ 仍存在。反向信号可以穿过冻结的层，继续传递到更前面的 Transformer 层及其中的 LoRA。数学上 $\partial L/\partial W$ 可以非零；**冻结不是宣称该导数为零，而是不给 W 执行参数更新**。

## 4. LoRA 放进大语言模型后如何训练

单层梯度公式并未改变。LLM 只是将 **Loss 从何而来** 这件事扩展为 Token 预测任务：输入序列产生 Logits，真实答案决定 Cross-Entropy，梯度回传到各个 LoRA 层。

### 4.1 指令数据如何变成 input_ids 与 labels

假设用户问“2+3 等于多少？”，标准答案是“5”。聊天模板将角色标记、问题、答案拼成一段序列，Tokenizer 再编码。下表的 Token 和 ID **人为构造，只演示位置对应关系**：

| 位置 | Token | `input_ids` | `labels` |
|---:|---|---:|---:|
| 0 | BOS | 1 | -100 |
| 1 | USER | 11 | -100 |
| 2 | 问题 | 42 | -100 |
| 3 | ASSISTANT | 12 | -100 |
| 4 | `5` | 57 | 57 |
| 5 | EOS | 2 | 2 |

在这里采用的 **Response-only SFT** 中，输入仍然包含整个问题和答案，但只让答案及 EOS 作为预测目标。`labels=-100` 表示对应目标位置的 Loss 不计入平均，**不是删除输入 Token**；问题仍会影响后面答案的预测。

三个常混淆的控制机制：

- `labels=-100`：指定**哪些预测目标**不计算 Loss；
- `attention_mask`：通常区分有效 Token 和 Padding；
- Causal Mask：使位置 $t$ **看不到未来的 Token**。

### 4.2 为什么 Logits 和 labels 要错一位

因果语言模型根据前缀预测下一个 Token：位置 $t$ 的 Logits 监督位置 $t+1$ 的目标。因此，上表中：

- 位置 **3** 的 Logits → 预测位置 **4** 的 `5`；
- 位置 **4** 的 Logits → 预测位置 **5** 的 EOS。

这就是 **shift 对齐**。虽然训练输入里已经有标准答案，模型在位置 3 预测 `5` 时不能借 Causal Attention 偷看后面的 `5`。

### 4.3 从 Token 到 LoRA 梯度的完整路径

```text
input_ids [Batch, Seq]
    ↓ Embedding
Hidden States [Batch, Seq, Hidden]
    ↓ Transformer 1 ... N（目标 Linear：W + sBA）
    ↓ LM Head
Logits [Batch, Seq, Vocab]
    ↓ 按 next-token 位置对齐 + 忽略 labels=-100
Token Cross-Entropy Loss
    ↓ 反向：LM Head → 各 Transformer → 各层 LoRA
得到各层 A、B 的梯度 → 优化器更新 → 下一轮前向
```

Logits 是词表分数，Softmax 后才是概率。对 $M$ 个参与监督的 Token，常用平均交叉熵：

$$\boxed{L=-\frac1M\sum_{t\in S}\log p_\theta(y_t\mid x_{<t})}$$

例如模型分别以 0.8 和 0.5 的概率预测正确的 `5` 和 EOS：

$$L=-\tfrac12(\ln0.8+\ln0.5)\approx0.4581$$

单个位置的 Softmax + Cross-Entropy 对 Logits 的梯度为 $p-y_{onehot}$（平均损失还要除以相应有效 Token 数）。梯度继续经过 LM Head、Attention、残差连接等运算，抵达第 $l$ 层的某个 LoRA 投影：

$$q_l=W_{Q,l}x_l+sB_{Q,l}A_{Q,l}x_l$$

此时上游网络给出局部梯度 $g_{Q,l}=\partial L/\partial q_l$，该层按第 3 节的公式得到自己的 $\nabla_{A_{Q,l}}L$、$\nabla_{B_{Q,l}}L$。**不同层的 Adapter 参数独立，但共同对最终 Token Loss 负责**，不是每层另算一个独立的语言建模损失。

训练时已知正确序列，可通过 Teacher Forcing 和 Causal Mask 并行计算不同位置的预测损失；推理时正确答案未知，通常自回归地逐 Token 生成。一次优化器更新也不必对应单个 Token，可汇总整个 Batch 或累积多个 Batch 的梯度。

## 5. 参数配置、Adapter、合并与显存

### 5.1 参数和插入位置分别控制什么

| 选择 | 直接作用 | 不能据此推断 |
|---|---|---|
| Rank $r$ | 更新最大秩、可训练参数量 | Rank 越大精度越高 |
| $\alpha$ | 分支缩放 $s=\alpha/r$ | $\alpha$ 就是学习率 |
| LoRA Dropout | 训练时在分支输入上施加正则化 | 改变低秩矩阵形状 |
| 插入位置 | 哪些 Linear 可以学习增量 | Q、V 必然是所有任务的最优选择 |

Self-Attention 中常见 $W_Q,W_K,W_V,W_O$。给 Q 添加 LoRA 会影响查询表示，可能改变 $\operatorname{softmax}(QK^T/\sqrt{d_k})$ 的注意力分布；给 V 添加 LoRA 会改变被聚合的信息。K、O 和 FFN 的线性层也可以适配。**插入位置决定“改哪里”，Rank 决定“每处有多少低秩容量”。**

### 5.2 为什么只保存 Adapter 就能复用

训练后的有效权重为：

$$W_{task}=W+sBA$$

因为 $W$ 没变，多个任务可以共享同一份基础模型，仅分别保存各自训练得到的 A、B 及其必要配置。**Adapter 本身不能独立推理**，必须搭配兼容的基础模型；实际复现输出还需匹配 Tokenizer、对话模板等。

推理时还可以提前合并：

$$\boxed{Wx+sBAx=(W+sBA)x},\qquad W_{merged}=W+sBA$$

这样不必运行独立的 LoRA 分支。这个等价关系是数学上的；浮点计算可能带来微小数值差异。若要频繁切换多个任务的 Adapter，不合并往往更方便。

### 5.3 为什么可训练参数少很多，显存却没按比例下降

训练显存可粗略分为：

$$M\approx M_{weights}+M_{gradients}+M_{optimizer}+M_{activations}+\cdots$$

| 显存组成 | 全参数微调 | 经典 LoRA |
|---|---|---|
| 基础模型 W | 需要 | **仍需要** |
| 基础 W 的梯度及优化器状态 | 需要 | 不需要 |
| LoRA A、B 的训练状态 | 无 | 需要，但通常较小 |
| 前向/反向激活值 | 需要 | 仍有显著开销 |

所以 LoRA 大幅减少了**基础参数的梯度和优化器状态**，并方便存储多个任务的 Adapter；却没有免去大模型自身的前向与必要反向计算。**训练参数减少 256 倍，不等于显存减少或训练加速 256 倍**。当基础模型权重本身仍太占空间时，就需要下一节的 QLoRA。

## 6. QLoRA：量化权重为什么仍能参与训练

经典 LoRA 通常用 FP16/BF16 等格式保存冻结的 W。**QLoRA 在低秩训练机制不变的前提下，改用 4-bit NF4 存储冻结的基础权重**：

$$\boxed{h=\widehat Wx+sBAx,\qquad\widehat W=D(W_{NF4})}$$

$D$ 是解量化，$\widehat W$ 是 W 的近似值。基础权重 4-bit **用于存储**，计算时按需解量化到 BF16 等计算精度；A、B 仍以较高精度训练。QLoRA **不是**让全部权重和梯度在 4-bit 整数上直接更新。

### 6.1 NF4：让 16 个量化等级适应权重分布

4-bit 只有 $2^4=16$ 种编码。若权重在归一化后大致服从正态分布，数据集中在 0 附近，那么等间距量化并不一定合适。**NF4（NormalFloat4）**依据这一分布特征设计非均匀的量化等级，并能精确表示零。

常见做法是分块量化：如每 64 个权重共享一个缩放常数，先归一化，再映射到 NF4 的某个等级；恢复时用该常数解量化。量化得到的是近似值 $\widehat W\ne W$，会产生误差。NF4 的优势依赖分布假设，**不是对任意权重分布都保证最优**。

### 6.2 Double Quantization：第二次量化的是“缩放常数”

第一次量化将 W 变为 **NF4 编码 + 每块缩放常数**。如果每 64 个权重有一个 FP32 常数，那么元数据平均开销为 $32/64=0.5$ bit/参数。

Double Quantization 再量化这些常数，而**不是把已经 4-bit 的权重继续量化**。在 QLoRA 原论文的分组假设下，平均元数据开销可近似估为：

$$\frac8{64}+\frac{32}{64\times256}\approx0.127\;\text{bit/参数}$$

因此相较 0.5 bit/参数，平均节省约 **0.373 bit/参数**。这是量化元数据的摊销估算，不是总显存的下降量。

### 6.3 Paged Optimizer：处理显存峰值而不是改变梯度

即使模型常驻权重变小，长序列、激活以及优化器更新仍可能造成瞬时显存峰值。Paged Optimizer 借助统一内存机制，在需要时将部分优化器状态于 GPU 显存和 CPU 内存之间分页迁移，以降低突发 OOM 风险。它不改变 LoRA 的数学公式；数据迁移也可能牺牲速度。

三者的分工可以归纳为：**NF4 压缩权重，Double Quantization 压缩量化元数据，Paged Optimizer 缓冲部分显存峰值**。

### 6.4 冻结的 4-bit 权重为什么能传递梯度

令 $g=\partial L/\partial h$。由于 W 不被训练，对 A、B 的局部导数仍是：

$$\boxed{\nabla_B L=s\,g(Ax)^T,\qquad \nabla_A L=s(B^Tg)x^T}$$

但更前面的 LoRA 层还需要从当前层取得输入梯度：

$$\boxed{\frac{\partial L}{\partial x}=\widehat W^Tg+sA^TB^Tg}$$

这里仍有 $\widehat W^Tg$：**冻结量化权重 ≠ 阻断梯度传播**。QLoRA 不必为了更新 W 而对离散量化编码求导，也不需要为此使用 STE。计算时解量化后的 $\widehat W$ 仍可参与输入梯度计算。

量化误差会改变前向输出及实际传回的梯度数值，因此 QLoRA 并不保证与未量化 LoRA 结果完全相同。以 70 亿参数粗估，FP16 权重约 14 GB，纯 4-bit 编码约 3.5 GB（十进制）；**后者不是 QLoRA 的实际总训练显存**，还需计入缩放常数、未量化部分、Adapter 状态和激活值。

## 7. 五种 LoRA 改进方法

这些方法解决的不是同一个问题。比较时始终看：**改了权重表达、缩放、优化器，还是初始化与参数分配？**

### 7.1 AdaLoRA：给不同层分配不同的有效 Rank

**问题**：所有层统一 $r=8$，可能有的层容量富余，有的层不足。

**改动**：用可训练的 SVD 风格分解表示增量：

$$\boxed{\Delta W=P\Lambda Q=\sum_i\lambda_iP_{:,i}Q_{i,:}}$$

$\Lambda$ 为对角矩阵，每个 $\lambda_i$ 控制一个秩 1 的更新分量。训练时利用梯度敏感度等信息评估分量重要性，按整体预算逐渐屏蔽低优先级的分量，让重要层保留更多有效 Rank；还涉及正交约束。

**对训练的影响**：前向从 $BAx$ 改为 $P\Lambda Qx$，梯度训练之外还多了重要性评分、预算调度和剪裁。**局限**：评分不一定准确；有效 Rank 被屏蔽不等于相关张量显存自动释放；训练流程更复杂。

### 7.2 rsLoRA：改变 Rank 增大时的缩放规律

**问题**：经典 LoRA 的 $s=\alpha/r$ 在高 Rank 下可能使有效训练尺度受到不合适的抑制。

**改动**：

$$\boxed{\frac{\alpha}{r}\ \longrightarrow\ \frac{\alpha}{\sqrt r}}$$

例如 $\alpha=16,r=64$：经典缩放为 0.25，rsLoRA 为 2。**A、B 形状不变，前向结构不变**；梯度公式里的 $s$ 同样换成 $\alpha/\sqrt r$。

**局限**：缩放系数相差 8 倍，不意味着真实梯度范数或模型效果相差 8 倍。$\alpha$、Rank 和学习率仍需匹配。

### 7.3 LoRA+：为 A、B 使用不同学习率

**问题**：A 负责形成低维特征，B 负责生成输出修正，两者的优化角色不同，同一学习率不一定高效。

**改动**：

$$\boxed{\eta_A=\eta,\qquad \eta_B=\lambda\eta\quad(\lambda>1\text{ 常见})}$$

**前向表达和梯度公式完全不变**，只是优化器对 A、B 采用不同更新尺度。**局限**：需要选择额外的学习率比例；B 学习率更高并不总能提高效果。

### 7.4 DoRA：显式分开学习权重的幅值和方向

**问题**：经典 $W+sBA$ 的加法通常同时改变权重向量的长度和方向，两者相互耦合。

**改动**：令 $v_j=(W_0+sBA)_{:,j}$ 为有效权重的第 $j$ 列，定义：

$$\boxed{W'_{:,j}=m_j\frac{v_j}{\|v_j\|_2}}$$

可训练的 $m_j$ 控制该列幅值；A、B 负责方向分支。一个直观例子：原列向量 $[3,4]^T$ 的长度为 5，方向分支变为 $[3,5]^T$；若 $m=5$ 不变，有效权重为 $5[3,5]^T/\sqrt{34}$，**方向已变，长度仍为 5**。

**对梯度的影响**：新增幅值参数 m 的梯度；归一化还会改变传到 A、B 的梯度路径（原论文也讨论了停止归一化因子梯度的简化策略）。**局限**：归一化与额外参数增加训练开销；并非每个任务都优于经典 LoRA。推理前通常仍可合并成完整权重。

### 7.5 PiSSA：从预训练权重的主奇异分量开始训练

**问题**：经典 LoRA 的 A 随机、B 为零，没有直接利用 W 中已有的主要矩阵方向，而且初始 A 的梯度为零。

**改动**：先对预训练 W 做 SVD：

$$W=U\Sigma V^T$$

取前 r 个主奇异分量（为方便理解，先设缩放 $s=1$）：

$$B_0=U_r\Sigma_r^{1/2},\qquad A_0=\Sigma_r^{1/2}V_r^T$$

把冻结权重改为残差：

$$W_{res}=W-B_0A_0,\qquad\boxed{W_{res}+B_0A_0=W}$$

**核心区别**：PiSSA 不只是改变 A、B 的初始化，还将冻结部分从完整 W 改成 $W_{res}$；初始有效权重仍等于预训练 W，但 A、B 已是非零且具有结构的矩阵，初次反向传播时两者通常都能获得梯度。

**局限**：SVD 或近似 SVD 有预处理成本；最大奇异值方向不保证就是下游任务最需要的方向；若 $s\ne1$，要调整初始化以保持初始等价。

## 8. 方法对照与容易混淆的边界

| 方法 | 主要修改位置 | 前向/梯度最重要的区别 |
|---|---|---|
| **经典 LoRA** | 低秩增量 | $W+sBA$；更新 A、B |
| **QLoRA** | 冻结基础权重的存储 | $\widehat W+sBA$；梯度经解量化 W 传递 |
| **AdaLoRA** | 跨层 Rank 预算 | $P\Lambda Q$；重要性评分与有效分量屏蔽 |
| **rsLoRA** | 分支缩放 | $\alpha/r\to\alpha/\sqrt r$，对应改变梯度尺度 |
| **LoRA+** | 优化器更新 | 公式不变；A、B 分学习率 |
| **DoRA** | 权重参数化 | 幅值与方向分开；新增 m 梯度和归一化路径 |
| **PiSSA** | 初始化与冻结残差 | $W_{res}+BA$；从主奇异分量出发 |

几个容易导致错误理解的边界：

| 常见误解 | 正确理解 |
|---|---|
| 冻结 W 后梯度就过不去了 | 不更新 W，但可以计算经过 W 的输入梯度 |
| B 初始化为 0，第一次反向传播没用 | A 初始梯度为 0，B 通常有非零梯度 |
| LoRA 参数少 256 倍，显存/速度也提升 256 倍 | 仍须保存基础模型，并计算必要激活和反向路径 |
| r 越大或方法越复杂，效果必然越好 | 表达容量、优化效果和泛化能力不是一回事 |
| `labels=-100` 意味着模型没看见该 Token | 它仍是上下文，仅不作为对应位置的损失目标 |
| QLoRA 的所有梯度都是 4-bit | 4-bit 主要是基础权重存储；Adapter 仍以较高精度训练 |
| Double Quantization 再量化 A、B | 二次量化的是第一次量化所需的缩放常数 |
| Adapter 文件就是完整模型 | 仍需兼容的基础模型及相关配置 |
| PiSSA 只等于换个初始化函数 | 还需从 W 扣除初始主分量，冻结剩余权重 |

**总的关系是：** 经典 LoRA 用低秩增量解决“训练全部权重太贵”；QLoRA 进一步解决“冻结的权重本身仍太占空间”；其余变体则分别改进低秩容量、训练尺度、优化策略、更新参数化和初始化。它们可以各自有效，但不能脱离模型、任务、数据和参数预算直接宣布某一种必然最好。
