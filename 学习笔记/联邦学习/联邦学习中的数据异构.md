# 联邦学习中的数据异构：分类、定义与典型问题

> **主题**：Data Heterogeneity in Federated Learning  
> **用途**：概念梳理、文献阅读与科研选题前的分类参考  
> **说明**：本文件以经典的五种 Non-IID 现象为基础，扩展介绍数据空间、质量、时间和监督信息等异构。各类型不是相互排斥的“唯一分类标准”，同一系统可能同时存在多种异构。

## 1. 什么是数据异构？

在联邦学习（Federated Learning, FL）中，多个客户端保留本地原始数据，通过协同训练获得共享模型或多个个性化模型。**数据异构（Data Heterogeneity）**是指客户端之间在数据的**统计分布、数量、质量、结构、可用信息或时间变化规律**等方面存在差异。

设客户端 $i$ 的数据集为 $D_i=\{(x_k,y_k)\}_{k=1}^{n_i}$，相应联合分布为 $P_i(x,y)$。经典统计异构通常体现为：

$$
P_i(x,y)\neq P_j(x,y),\qquad i\neq j.
$$

其中：

- $x$：输入特征，例如图像、传感器读数或文本；
- $y$：学习目标，例如类别标签或连续预测值；
- $n_i$：客户端 $i$ 的样本量；
- $P_i$：客户端 $i$ 的数据分布。

**重要边界**：数据异构不等同于系统异构（算力、网络、设备掉线），也不等同于模型异构（不同网络架构）。后两者可能与数据异构共同出现，但应分别分析。[1][2]

## 2. 分类总览

| 层次 | 具体分类 | 核心差异 | 典型问题 |
|---|---|---|---|
| **A. 经典统计异构** | 特征分布异构（Feature Distribution Skew） | $P_i(x)$ 不同 | 不同客户端数据风格、数值范围不同 |
| | 标签分布异构（Label Distribution Skew） | $P_i(y)$ 不同 | 各类样本占比不同 |
| | 同标签、不同特征（Conditional Feature Shift） | $P_i(x\mid y)$ 不同 | 同类别在不同客户端的表现不同 |
| | 同特征、不同标签（Conditional Label Shift） | $P_i(y\mid x)$ 不同 | 同一输入在各客户端对应不同目标 |
| | 数据量异构（Quantity Skew） | $n_i$ 不同 | 大小客户端样本数差异显著 |
| **B. 数据结构异构** | 特征空间异构（Feature-space Heterogeneity） | 输入字段、维度或语义不一致 | 无法直接共用相同输入接口 |
| | 模态异构（Modality Heterogeneity） | 模态组合不一致 | 图像、文本、音频等可用性不同 |
| | 标签空间／任务异构（Label-space / Task Heterogeneity） | 输出集合或任务定义不一致 | 客户端预测目标不同 |
| **C. 数据可用性与质量异构** | 数据质量异构（Quality Heterogeneity） | 噪声、异常、错误率不同 | 低质量更新可能影响训练 |
| | 标签可用性异构（Label Availability Heterogeneity） | 有标签比例不一致 | 有监督、少标签、无标签客户端并存 |
| **D. 动态与位置异构** | 时间分布异构（Temporal Heterogeneity） | 数据分布随时间变化 | 概念漂移、季节变动、持续适应 |
| | 空间／地域异构（Spatial Heterogeneity） | 地理或环境条件不同 | 跨地区数据差异、域迁移 |

**分类说明**：A 组的五种形式直接对应经典联邦学习综述对非同分布现象的讨论。 B—D 组是面向更广泛真实应用的扩展整理，**不应被描述为经典文献中与前五类并列且完全互斥的官方十二分类**。

## 3. A 类：经典统计异构（Statistical Heterogeneity）

### 3.1 特征分布异构（Feature Distribution Skew）

**定义**：客户端输入数据的边缘分布不同。其典型理想化形式为：

$$
P_i(x)\neq P_j(x),\qquad P_i(y\mid x)=P_j(y\mid x).
$$

**例子**：不同手机用户书写同一个字符时，笔画粗细、倾斜角度和书写速度不同；不同工厂的传感器取值范围不同。

**可能影响**：共享模型在部分客户端上泛化较差，局部训练更新方向不同；但如果目标映射 $P(y\mid x)$ 真正共享，统一模型仍可能是合理选择，不能仅因 $P(x)$ 不同就断言必须个性化。

**常见研究问题**：领域泛化、特征对齐、客户端归一化、对不同输入分布的鲁棒学习。

**识别与构造**：对比均值、方差、分位数、特征嵌入或分布距离；可以通过真实设备/地区分组，或者对客户端施加不同风格、噪声和采集条件来控制差异程度。

### 3.2 标签分布异构（Label Distribution Skew）

**定义**：客户端标签类别的比例不同。典型理想化形式为：

$$
P_i(y)\neq P_j(y),\qquad P_i(x\mid y)=P_j(x\mid y).
$$

**例子**：医院 A 的某疾病阳性样本较多，医院 B 主要是阴性样本；不同用户的文本或表情类别出现频率不同。

**可能影响**：少数类别在某些客户端几乎不可见，局部模型偏向常见类别，聚合后可能损害低频类别识别能力。

**常见研究问题**：类别不平衡、客户端漂移、类别感知聚合、长尾泛化、公平性。

**识别与构造**：统计各客户端类别频率及 Jensen–Shannon 散度等；常用 Dirichlet 划分构造可控的类别比例差异。**注意：Dirichlet 划分只模拟某一类 Non-IID，不代表全部数据异构。**

### 3.3 同标签、不同特征（Same Label, Different Features）

**定义**：类别相同，但该类数据在不同客户端的具体表现不同：

$$
P_i(x\mid y)\neq P_j(x\mid y).
$$

**例子**：不同医院使用不同成像设备，同一种疾病的影像风格和纹理不同；不同地区拍摄的“汽车”因天气和场景而表现不同。

**可能影响**：模型可能学习到某一客户端特有的外观、背景或采集伪相关，而不能提取真正可迁移的目标特征。

**常见研究问题**：条件分布对齐、域不变表示、跨设备泛化、鲁棒特征提取。

**识别与构造**：在相同标签内分析客户端之间的特征差异；可以按设备、来源、图像风格分组。

**与 3.1 的区别**：$P(x\mid y)$ 和 $P(x)$ 不是同一个量，两类现象可能同时出现，不能视为严格互斥。

### 3.4 同特征、不同标签（Same Features, Different Labels）

**定义**：相似输入在不同客户端的目标标签或映射规则不同：

$$
P_i(y\mid x)\neq P_j(y\mid x).
$$

**例子**：不同用户对同一文本表达的情绪判断不同；相似行为特征在不同群体中对应的风险标签规律不同。

**可能影响**：如果同一输入对应的目标映射确实不一致，强行学习一个统一映射可能产生客户端间冲突；这时个性化、分群学习或多任务学习具有更直接的动机。

**常见研究问题**：个性化联邦学习（PFL）、客户端聚类、混合专家、任务条件化建模。

**识别与构造**：在可比输入条件下观察标签或目标关系差异。**需要区分：标签标注错误属于质量问题；用户目标本来不同属于任务/偏好差异，不应全部混称为随机 Non-IID。**

### 3.5 数据量异构（Quantity Skew / Unbalancedness）

**定义**：客户端持有的样本量显著不同：

$$
n_i\neq n_j.
$$

**例子**：客户端 A 拥有一年记录，客户端 B 只有一周记录；大型医院积累了远多于小型医院的样本。

**可能影响**：样本多的客户端可能主导聚合；样本少的客户端估计不稳定。但其后果也取决于采样、模型、加权方式和其他分布差异，**数量不均本身不必然造成精度下降**。

**常见研究问题**：样本量感知聚合、少样本个性化、客户端公平性、冷启动。

**识别与构造**：报告 $n_i$ 的范围、标准差、最大最小比；可对不同客户端设置不同抽样比例，同时保持其他分布因素相对稳定。

## 4. B 类：数据结构异构（Data-space / Structural Heterogeneity）

### 4.1 特征空间异构（Feature-space Heterogeneity）

**定义**：各客户端拥有的输入特征集合、维度或语义结构不一致：

$$
\mathcal X_i\neq\mathcal X_j.
$$

**例子**：某医院拥有检验数据与影像，另一医院只有检验数据；不同企业记录的客户属性字段不同。

**可能影响**：模型输入层不兼容，不能直接将同一网络应用到所有客户端，简单参数平均也可能失去意义。

**常见研究问题**：特征对齐、共享表示空间、特征缺失建模、知识蒸馏、联邦迁移学习。

**识别与构造**：明确记录各客户端特征字段与缺失模式，并区分“该特征本来不存在”与“该特征存在但测量缺失”。

**边界说明**：特征空间异构与 3.1 的特征分布异构**不是同一概念**。前者是“字段是否相同”，后者是“字段相同时，数值分布是否相同”。特征空间不一致也是纵向联邦学习、异构联邦迁移学习的重要问题背景，但并非所有特征空间异构都属于同一种联邦设置。

### 4.2 模态异构（Modality Heterogeneity）

**定义**：客户端拥有的数据模态或模态组合不同。模态可包括图像、文本、音频、视频、结构化传感器数据等。

**例子**：客户端 A 有图像和文本，客户端 B 只有文本，客户端 C 有音频和视频。

**可能影响**：不同客户端可能需要不同编码器，模态表征及参数空间难以直接聚合，部分客户端因缺失关键模态而性能下降。

**常见研究问题**：多模态联邦学习、模态缺失鲁棒学习、跨模态对齐、知识蒸馏、模态无关表示。[3]

**识别与构造**：记录每端拥有的模态集合，以及训练或推理期间的模态缺失比例。

**与特征空间异构的关系**：模态异构可以看作涉及数据类型/表征方式差异的更具体结构问题；多个数值型字段不同，通常不宜仅因此称为多模态异构。

### 4.3 标签空间／任务异构（Label-space / Task Heterogeneity）

**定义**：不同客户端的可用输出类别集合不同，或者训练目标本身不同：

$$
\mathcal Y_i\neq\mathcal Y_j
$$

或者客户端拥有不同的任务损失 $\mathcal L_i$。

**例子**：不同机构分别识别不同疾病集合；客户端 A 做分类，客户端 B 做回归；两个机构对同一预测结果采用不同业务目标。

**可能影响**：不同客户端的输出头与损失函数不可直接统一，需要任务特定模块或共享表示。

**常见研究问题**：多任务联邦学习、共享骨干与私有任务头、任务迁移、个性化输出层。

**边界说明**：它跨越“数据结构”与“学习目标”两个层面。**某客户端缺少部分标签类别的样本，不一定意味着它的任务标签空间发生变化**；任务目标不同时，也不宜全部归结为数据分布偏移。

## 5. C 类：数据可用性与质量异构

### 5.1 数据质量异构（Data Quality Heterogeneity）

**定义**：不同客户端的观测可靠性、完整性、准确性或噪声水平不同。

**主要形式**：

- **标签噪声**：部分标签标注错误，各端错误率不同；
- **测量噪声**：传感器受精度、环境干扰影响；
- **缺失数据**：某些记录、时间段或字段缺失；
- **异常值**：错误峰值、设备故障、重复或损坏记录；
- **系统性偏差**：长期校准偏移，未必能通过随机噪声假设解释。

**可能影响**：本地模型学习到错误模式，客户端更新可靠性不同，聚合时难以分辨真实的域差异与数据质量问题。

**常见研究问题**：噪声鲁棒联邦学习、客户端可靠性评估、质量感知聚合、缺失数据插补、异常检测。

**识别与构造**：分别报告缺失率、噪声强度、异常比例和标注错误率；可以给不同客户端设置不同扰动等级，并同时保存干净测试集。

**边界说明**：数据质量异构不等于恶意数据投毒；无意的采集错误与有目的的攻击应区别评价。

### 5.2 标签可用性异构（Label Availability Heterogeneity）

**定义**：不同客户端拥有的标注样本比例不一致，可能同时存在全标注、少量标注与无标注客户端。

**例子**：大型研究机构有专家标注数据，普通终端只有大量未标注记录。

**可能影响**：常规监督学习的本地损失在无标签客户端上无法直接计算，导致样本利用率与训练目标不一致。

**常见研究问题**：半监督联邦学习、自监督学习、伪标签、联邦迁移与知识蒸馏。

**识别与构造**：记录客户端标签覆盖率 $r_i=n_i^{labeled}/n_i$，分设全标注、少标签、无标签组。

**与标签分布异构的区别**：标签分布异构关注“已标注的不同类别占比”，标签可用性异构关注“有多少样本存在有效标注”。

## 6. D 类：动态与空间异构

### 6.1 时间分布异构（Temporal Heterogeneity）

**定义**：客户端的数据具有时序相关性，或者其数据分布随着时间变化。可表示为：

$$
P_{i,t}(x,y)\neq P_{i,t+\Delta}(x,y).
$$

**例子**：用户习惯改变、季节性变化、传感器老化、业务规则变化；不同客户端在不同月份呈现不同峰谷规律。

**可能影响**：过去训练出的共享模型或本地模型在新时段失效；不同客户端漂移发生的时点与强度不同，使统一更新节奏不适用。

**常见研究问题**：概念漂移检测、联邦持续学习、在线适应、灾难性遗忘、漂移感知个性化。[6]

**需要区分三个概念**：

1. **跨客户端静态时序差异**：例如 A 长期早高峰、B 长期晚高峰；这可以体现为特征/条件分布异构，**不自动构成时间漂移**。
2. **客户端内部的时间漂移**：例如 A 在某个时点从早高峰变为晚高峰。
3. **序列相关性（Non-independence）**：连续时间样本存在相关性；它与跨客户端分布不一致是不同维度。

### 6.2 空间／地域异构（Spatial / Geographical Heterogeneity）

**定义**：不同地域、环境或场所的客户端具有不同数据分布，可表现为 $P(x)$、$P(y)$ 或条件分布差异。

**例子**：不同地区气候条件不同，导致传感器、交通、建筑能耗数据规律不同；地区语言习惯使文本分布不同。

**可能影响**：模型在未见过的地区泛化不足；仅按位置分组不一定能准确刻画真实差异。

**常见研究问题**：跨域泛化、跨地区个性化、地理聚类、空间表征迁移。

**边界说明**：空间异构通常是**产生统计异构的来源或组织维度**，而不总是独立于 $P(x)$ / $P(y)$ 的新概率分类。

## 7. 复合异构（Compound / Mixed Heterogeneity）

现实联邦系统往往同时存在多种异构。例如：

- 标签分布异构 + 数据量异构：某客户端既缺少某些类别，样本总量也很小；
- 特征分布异构 + 数据质量异构：不同设备测量范围不同，且部分设备噪声更大；
- 时间漂移 + 数据量异构：新加入客户端的数据少，老客户端又发生分布变化；
- 特征空间异构 + 模态缺失：不同客户端本来具有不同字段，有些客户端还缺少整个模态。

**科研含义**：复合异构通常更贴近现实，但一开始不宜同时改变所有因素。建议先控制单因素，验证其单独影响，再加入第二个因素分析交互作用。

## 8. 不同类型之间最容易混淆的概念

| 易混概念 | 正确区分方式 |
|---|---|
| Feature Skew vs Feature-space Heterogeneity | 前者输入字段相同但值的分布不同；后者字段/维度/语义空间不同 |
| Label Skew vs Label-space Heterogeneity | 前者标签集合通常相同但占比不同；后者客户端任务可定义不同输出集合 |
| Same Features, Different Labels vs Label Noise | 前者可能是真实目标映射差异；后者是观测标签有错误 |
| 时序异构 vs 概念漂移 | 时间曲线不同不代表分布随时间改变；漂移需要比较先后时间段 |
| 数据量异构 vs 缺失数据 | 前者是记录总数差异；后者是应有记录或字段不完整 |
| 用户偏好/奖励异构 vs 数据分布异构 | 偏好不同首先是目标/任务差异，可能与数据异构共同出现 |
| 统计异构 vs 系统异构 | 统计异构属于数据；客户端算力和网络差异属于系统 |
| 数据异构 vs 负迁移 | 异构是一种数据条件；负迁移是待验证的学习结果，不能默认必然发生 |

## 9. 如何从科研角度选择一种异构？

选题时可以依次回答以下问题：

1. **异构对象是什么？** 是标签比例、输入分布、特征集合、质量还是时间变化？
2. **差异如何量化？** 是否有可计算的分布距离、统计量或缺失率？
3. **它为何妨碍协同学习？** 是局部更新冲突、特征不兼容、标签不足，还是模型无法适应变化？
4. **它是否一定需要个性化？** 如果共享条件映射仍成立，个性化未必比充分训练的全局模型更好。
5. **实验如何排除混杂因素？** 尽量固定客户端数量、数据量、任务、训练预算、模型大小和评测流程。
6. **研究结论能否跨客户端/数据集成立？** 至少评估平均性能、最差客户端性能，并在独立切分或独立数据来源上复核。

| 科研目的 | 优先考虑的异构 |
|---|---|
| 研究传统 Non-IID 与聚合收敛 | 标签分布、特征分布、数据量异构 |
| 研究个性化是否必要 | 条件标签分布差异、持续性的客户端特定规律、任务差异（需明确边界） |
| 研究鲁棒性 | 数据质量、标签噪声、缺失数据 |
| 研究持续学习 | 客户端内部时间漂移与跨客户端漂移不同步 |
| 研究异构输入与模型适配 | 特征空间、模态组合、标签空间异构 |

> **关键结论**：构造出 Non-IID 只证明客户端数据不同；要证明某个个性化算法有效，还需要展示该异构条件下确实出现了可度量的协同学习问题，并验证算法能够缓解这一问题。
