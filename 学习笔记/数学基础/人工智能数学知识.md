## 模块一：线性代数

**定位：** 整个 AI 数学体系的语言和骨架，必须最先掌握。

**核心章节：**

1. 标量、向量、矩阵、张量的定义与直觉
2. 矩阵运算：加法、乘法、转置、逆
3. 线性变换的几何意义
4. 特殊矩阵：单位矩阵、对角矩阵、正交矩阵、对称矩阵
5. 行列式与秩
6. 特征值与特征向量
7. 奇异值分解（SVD）
8. 范数（L1、L2、Frobenius）

**AI 连接点：**

- 神经网络层 = 矩阵乘法
- Transformer 注意力 = QKV 矩阵运算
- 词向量 = 高维空间中的向量
- 模型压缩（LoRA）= 低秩矩阵分解

---

## 模块二：微积分与自动微分

**定位：** 神经网络"学习"的数学机制，理解训练过程的关键。

**核心章节：**

1. 导数的直觉：变化率与切线
2. 常见函数的导数（指数、对数、三角函数）
3. 多变量函数与偏导数
4. 梯度的几何意义
5. **链式法则**（反向传播的核心）
6. 方向导数与梯度下降的关系
7. 计算图（Computational Graph）
8. 自动微分（Autograd）的工作原理
9. 二阶导数与 Hessian 矩阵（进阶）

**AI 连接点：**

- 反向传播 = 链式法则的系统性应用
- PyTorch / JAX 的 `.backward()` = 自动微分
- 梯度爆炸/消失 = 链式法则连乘的数值问题

---

## 模块三：概率论与统计

**定位：** AI 对"不确定性"建模的数学基础，生成模型和决策模型的核心。

**核心章节：**

1. 概率空间：事件、样本空间、概率公理
2. 条件概率与独立性
3. 贝叶斯定理与贝叶斯思维
4. 常见概率分布：伯努利、多项式、高斯、均匀分布
5. 期望、方差、协方差
6. 大数定律与中心极限定理
7. 最大似然估计（MLE）
8. 最大后验估计（MAP）
9. 蒙特卡洛方法与采样
10. 变分推断初步

**AI 连接点：**

- Softmax 输出 = 多项分布的概率
- Dropout = 伯努利随机采样
- LLM 生成文字 = 对词汇表做概率采样
- VAE / Diffusion = 概率分布的学习与采样

## 模块四：信息论

**定位：** 理解损失函数和表示学习的理论支柱，内容精炼但影响深远。

**核心章节：**

1. 信息量与自信息
2. 熵（Shannon Entropy）
3. 联合熵与条件熵
4. 互信息（Mutual Information）
5. 交叉熵与 KL 散度
6. JS 散度
7. 信息瓶颈理论（进阶）

**AI 连接点：**

- 交叉熵损失函数 = 信息论中的交叉熵
- KL 散度 = RLHF 中约束策略偏离程度
- 互信息 = 对比学习（CLIP）的理论基础
- 信息瓶颈 = 理解神经网络"压缩"数据的方式

## 模块五：优化理论

**定位：** 模型训练的引擎，直接决定模型能否收敛、收敛快慢和最终性能。

**核心章节：**

1. 优化问题的基本形式：目标函数、约束、可行域
2. 凸函数与凸优化
3. 鞍点、局部最小值、全局最小值
4. 一阶方法：梯度下降、随机梯度下降（SGD）
5. 动量法（Momentum）
6. 自适应学习率：AdaGrad、RMSProp、Adam、AdamW
7. 学习率调度：Warmup、Cosine Decay、ReduceLROnPlateau
8. 正则化的数学：L1（稀疏性）、L2（权重衰减）
9. 约束优化：拉格朗日乘数法、KKT 条件
10. 二阶优化方法（牛顿法、L-BFGS）

**AI 连接点：**

- Adam 的 $\beta_1, \beta_2$ = 梯度一阶/二阶矩的指数移动平均
- Warmup = 训练初期避免大梯度破坏初始化
- Weight Decay = L2 正则化的参数化形式
- 大模型训练不稳定 = 非凸优化的挑战

这部分按照 AI 四大方向，各自有侧重的数学内容。

### 6A · LLM 与 Transformer

- 余弦相似度与对比学习损失（InfoNCE / NT-Xent）

- 刚体变换：旋转矩阵（SO(3)）、齐次坐标

- 贝叶斯滤波：卡尔曼滤波、粒子滤波

## 贯穿全程的学习原则

**① 公式不是终点，直觉是终点** 每个公式都要问自己：它的几何/物理意义是什么？在 AI 中对应哪个操作？

**② 代码验证理解** 每学一个概念，用 NumPy / PyTorch 写几行代码验证，比死记公式有效十倍。

**③ 用论文倒逼学习** 遇到不懂的公式，查清楚它属于哪个数学模块，回来针对性补充，形成闭环。

**④ 先宽后深** 先把所有模块过一遍，建立全局地图，再针对自己的方向深入钻研。
