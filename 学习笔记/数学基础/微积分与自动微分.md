# 微积分与自动微分

## 第一章 · 导数的直觉：变化率与切线

### 1.1 导数是什么

导数回答一个问题：**当输入变化一点点，输出会变化多少？**

设函数 $f(x)$，导数的严格定义是：

$$f'(x) = \frac{df}{dx} = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

用人话说：把输入 $x$ 往右推一个无穷小量 $\Delta x$，输出变化了多少，两者的比值就是导数。

---

### 1.2 几何意义：切线的斜率

$$f'(x_0) = \text{函数在 } x_0 \text{ 处切线的斜率}$$

```
      f(x)
       │        /  ← 切线，斜率 = f'(x₀)
       │      ╱·
       │    ╱  ·  ← 曲线 f(x)
       │  ╱
       │╱
───────┼──────────── x
       x₀
```

- 斜率为正 → 函数在该点递增
- 斜率为负 → 函数在该点递减
- 斜率为零 → 函数在该点是极值（极大或极小）

---

### 1.3 物理直觉

|函数 $f(t)$|导数 $f'(t)$|
|---|---|
|位移（米）|速度（米/秒）|
|速度（米/秒）|加速度（米/秒²）|
|损失函数 $L(w)$|损失对参数的变化率 → **梯度**|

**在 AI 中：** 损失函数 $L$ 对参数 $w$ 的导数 $\frac{dL}{dw}$，告诉我们"把参数 $w$ 增大一点点，损失会增大还是减小、增减多少"。这正是训练神经网络的核心信息。

---

## 第二章 · 常见函数的导数

这些导数公式需要熟记，因为它们在 AI 论文中频繁出现。

### 2.1 基本导数表

|函数 $f(x)$|导数 $f'(x)$|AI 中的出现位置|
|---|---|---|
|$c$（常数）|$0$|偏置项的初始分析|
|$x^n$|$nx^{n-1}$|多项式激活函数|
|$e^x$|$e^x$|指数函数，出现在 Softmax|
|$\ln x$|$\dfrac{1}{x}$|交叉熵损失的求导|
|$\sin x$|$\cos x$|位置编码（Sinusoidal PE）|
|$\cos x$|$-\sin x$|位置编码|
|$\sigma(x) = \dfrac{1}{1+e^{-x}}$|$\sigma(x)(1-\sigma(x))$|Sigmoid 激活函数|

### 2.2 几个关键激活函数的导数

**Sigmoid：** $$\sigma(x) = \frac{1}{1+e^{-x}}, \quad \sigma'(x) = \sigma(x)(1 - \sigma(x))$$

注意：当 $x$ 很大或很小时，$\sigma'(x) \to 0$，这就是"梯度消失"的根源之一。

**ReLU：** $$\text{ReLU}(x) = \max(0, x), \quad \text{ReLU}'(x) = \begin{cases} 1 & x > 0 \ 0 & x \leq 0 \end{cases}$$

ReLU 的导数极其简单，计算快速，这是它取代 Sigmoid 成为主流激活函数的核心原因。

**GELU（GPT 系列使用）：** $$\text{GELU}(x) \approx x \cdot \sigma(1.702x)$$

其导数较复杂，但 PyTorch 会自动计算，不需要手推。

## 第三章 · 多变量函数与偏导数

神经网络有数十亿个参数，损失函数是这些参数的多变量函数，需要对每个参数分别求导。

### 3.1 偏导数

对多变量函数 $f(x_1, x_2, \ldots, x_n)$，对某个变量 $x_i$ 求偏导数时，**把其他变量当作常数**：

$$\frac{\partial f}{\partial x_i} = \lim_{\Delta x_i \to 0} \frac{f(\ldots, x_i + \Delta x_i, \ldots) - f(\ldots, x_i, \ldots)}{\Delta x_i}$$

**例子：** $f(x, y) = 3x^2 + 2xy + y^3$

$$\frac{\partial f}{\partial x} = 6x + 2y \quad \text{（把 y 当常数）}$$

$$\frac{\partial f}{\partial y} = 2x + 3y^2 \quad \text{（把 x 当常数）}$$

---

### 3.2 梯度（Gradient）

梯度是所有偏导数组成的向量，记作 $\nabla f$：

$$\nabla f = \begin{bmatrix} \dfrac{\partial f}{\partial x_1} \ \dfrac{\partial f}{\partial x_2} \ \vdots \ \dfrac{\partial f}{\partial x_n} \end{bmatrix}$$

**梯度的几何意义：梯度方向 = 函数增长最快的方向；梯度的模 = 该方向的增长速率。**

```
等高线图（俯视）：

    ↑ y
    │     ·····
    │   ···○···     ○ = 当前位置
    │     ↗·····    ↗ = 梯度方向（最陡上升）
    │   ·····
    └──────────── x

沿梯度方向走：函数值增加最快
沿负梯度方向走：函数值减小最快 ← 这就是梯度下降！
```

**在 AI 中：** 训练神经网络时，损失函数 $L$ 关于所有参数 $\theta$ 的梯度是：

$$\nabla_\theta L = \begin{bmatrix} \frac{\partial L}{\partial w_1} \ \frac{\partial L}{\partial w_2} \ \vdots \ \frac{\partial L}{\partial b_1} \ \vdots \end{bmatrix}$$

一个拥有 70 亿参数的模型，这个梯度向量就有 70 亿个分量。

---

## 第四章 · 链式法则（最核心）

链式法则是整个深度学习的数学心脏，反向传播算法完全建立在它之上。

### 4.1 单变量链式法则

如果 $y = f(u)$，$u = g(x)$，那么：

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

**例子：** $y = \sin(x^2)$，令 $u = x^2$，则 $y = \sin(u)$：

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = \cos(u) \cdot 2x = 2x\cos(x^2)$$

---

### 4.2 多变量链式法则

如果 $L$ 依赖于 $y$，$y$ 依赖于 $x$，$x$ 又依赖于 $w$：

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x} \cdot \frac{\partial x}{\partial w}$$

导数沿着依赖链**一路相乘**传递回去。

---

### 4.3 为什么链式法则对神经网络如此重要

考虑一个简单两层网络：

```
输入 x → [层1: z₁=W₁x+b₁] → [激活: a₁=ReLU(z₁)] → [层2: z₂=W₂a₁+b₂] → 输出 ŷ → 损失 L
```

我们想求 $\frac{\partial L}{\partial W_1}$（损失对第一层权重的梯度），链式法则给出：

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial W_1}$$

每一项都是局部的、容易计算的导数，链式法则把它们串联起来，这就是**反向传播**的本质。

## 第五章 · 梯度下降

### 5.1 基本思想

目标：找到使损失 $L(\theta)$ 最小的参数 $\theta$。

策略：沿着负梯度方向（下坡方向）不断迈步。

$$\theta \leftarrow \theta - \eta \cdot \nabla_\theta L$$

其中 $\eta$ 是**学习率**，控制每步的步长。

```
损失 L
  │\
  │ \           每次迭代，沿坡面向下滚动
  │  \   ↙
  │   \_/
  └──────── θ
       ↑
    最小值（我们的目标）
```

---

### 5.2 学习率的影响

```
η 太小：              η 合适：             η 太大：
  │\                   │\                   │\
  │ \··                │ \                  │ \/\/\
  │  \··               │  \_/              ↑  发散！
  │   \···             └──────
  └──────
收敛极慢              顺利收敛            震荡或发散
```

**在 AI 中：** 学习率是最重要的超参数之一，通常取 $10^{-4}$ 到 $10^{-2}$ 之间，大模型训练常用 $3 \times 10^{-4}$。

---

### 5.3 三种梯度下降变体

**批量梯度下降（Batch GD）：**

$$\theta \leftarrow \theta - \eta \cdot \frac{1}{N}\sum_{i=1}^N \nabla L_i(\theta)$$

用全部 $N$ 个样本计算梯度，精确但极慢。

**随机梯度下降（SGD）：**

$$\theta \leftarrow \theta - \eta \cdot \nabla L_i(\theta)$$

每次只用 1 个样本，快速但噪声大、不稳定。

**小批量梯度下降（Mini-batch GD）：** ← 实际使用的

$$\theta \leftarrow \theta - \eta \cdot \frac{1}{B}\sum_{i \in \text{batch}} \nabla L_i(\theta)$$

取 $B$（batch size）个样本，在效率和稳定性之间取得平衡。实际训练中 batch size 通常取 32、64、128、256 等。

## 第六章 · 计算图（Computational Graph）

计算图是理解自动微分的关键工具，也是 PyTorch 等框架的工作原理。

### 6.1 什么是计算图

把数学运算表示为有向图，每个节点是一次运算，边是数据的流动方向。

**例子：** 计算 $L = (x \cdot w + b)^2$，令 $x=2, w=3, b=1$

```
前向传播（Forward Pass）：

    x=2 ──┐
           ├──[×]── z=6 ──┐
    w=3 ──┘               ├──[+]── a=7 ──[²]── L=49
                   b=1 ──┘

数据流：从左到右，计算最终损失
```

---

### 6.2 反向传播（Backward Pass）

反向传播沿计算图**从右到左**传递梯度，每经过一个节点就应用一次链式法则。

```
反向传播（Backward Pass）：

∂L/∂x ←─┐
          ├──[×的反向]←── ∂L/∂z ←─┐
∂L/∂w ←─┘                          ├──[+的反向]←── ∂L/∂a ←── [²的反向] ←── ∂L/∂L=1
                          ∂L/∂b ←─┘

梯度流：从右到左，逐层计算各参数的梯度
```

逐步计算：

$$\frac{\partial L}{\partial L} = 1$$

$$\frac{\partial L}{\partial a} = \frac{\partial (a^2)}{\partial a} = 2a = 14$$

$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} = 14 \cdot 1 = 14$$

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial w} = 14 \cdot x = 14 \times 2 = 28$$

$$\frac{\partial L}{\partial b} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial b} = 14 \cdot 1 = 14$$

---

### 6.3 多层网络的计算图

一个真实的神经网络计算图长这样：

```
          输入层         隐藏层1          隐藏层2         输出层
           x
           │
           ▼
    [×W₁]──[+b₁]──[ReLU]──[×W₂]──[+b₂]──[ReLU]──[×W₃]──[+b₃]──[Softmax]──L
           
    ←─────────────────── 反向传播 ──────────────────────────────────────────
    ∂L/∂W₁          ∂L/∂W₂                            ∂L/∂W₃
```

无论网络多深，反向传播就是沿着这张图从右到左地应用链式法则，PyTorch 自动帮你完成这一切。

## 第七章 · 自动微分（Autograd）

### 7.1 自动微分 vs 数值微分 vs 符号微分

**数值微分：** 用有限差分近似导数，$f'(x) \approx \frac{f(x+h) - f(x)}{h}$。

- 缺点：有截断误差，计算量是参数数量的两倍。

**符号微分：** 用代数规则推导导数表达式（如 Mathematica）。

- 缺点：表达式膨胀，不适合大规模计算。

**自动微分（AD）：** 在执行前向计算的同时，精确记录并反向传播梯度。

- 优点：精确、高效，与网络规模无关。**这是 PyTorch/JAX 使用的方法。**

---

### 7.2 PyTorch Autograd 的工作原理

```python
import torch

x = torch.tensor(2.0, requires_grad=True)  # 标记需要计算梯度
w = torch.tensor(3.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

# 前向传播：PyTorch 悄悄建立计算图
z = x * w          # z = 6
a = z + b          # a = 7
L = a ** 2         # L = 49

# 反向传播：沿计算图传递梯度
L.backward()

print(w.grad)   # ∂L/∂w = 28.0  ✓
print(b.grad)   # ∂L/∂b = 14.0  ✓
print(x.grad)   # ∂L/∂x = 42.0  (= 2a·w = 14·3)  ✓
```

PyTorch 在每次运算时，同时记录"这个运算如何对输入求导"，构成动态计算图。调用 `.backward()` 时，沿图反向应用链式法则。

---

### 7.3 动态图 vs 静态图

|动态图（PyTorch）|静态图（早期 TensorFlow）|
|---|---|---|
|图的构建时机|每次前向传播时动态构建|运行前一次性定义|
|调试|容易，可以打印中间值|困难|
|灵活性|高（if/for 都可以）|低|
|优化性能|稍弱|更强|

现代框架（PyTorch 2.0+、JAX）都支持动态图，同时可以编译成静态图加速（`torch.compile`）。

## 第八章 · 反向传播的完整推导

现在把所有知识串联起来，完整推导一个两层神经网络的反向传播。

### 8.1 网络结构

$$ \mathbf{x} \xrightarrow{W_1, b_1} \mathbf{z}_1 = W_1\mathbf{x} + b_1 \xrightarrow{\text{ReLU}} \mathbf{a}_1 \xrightarrow{W_2, b_2} \mathbf{z}_2 = W_2\mathbf{a}_1 + b_2 \xrightarrow{\text{Softmax}} \hat{\mathbf{y}} \xrightarrow{} L $$

损失函数使用交叉熵： $$L = -\sum_c y_c \log \hat{y}_c$$

---

### 8.2 逐层反向传播

**第一步：** 输出层梯度（Softmax + 交叉熵的组合有简洁结果）

$$\frac{\partial L}{\partial \mathbf{z}_2} = \hat{\mathbf{y}} - \mathbf{y}$$

这是个极其优美的结果：输出梯度 = 预测值 - 真实标签。预测越偏离真实，梯度越大。

**第二步：** 第二层权重的梯度

$$\frac{\partial L}{\partial W_2} = \frac{\partial L}{\partial \mathbf{z}_2} \cdot \mathbf{a}_1^T$$

$$\frac{\partial L}{\partial b_2} = \frac{\partial L}{\partial \mathbf{z}_2}$$

**第三步：** 传递到隐藏层

$$\frac{\partial L}{\partial \mathbf{a}_1} = W_2^T \cdot \frac{\partial L}{\partial \mathbf{z}_2}$$

**第四步：** 通过 ReLU

$$\frac{\partial L}{\partial \mathbf{z}_1} = \frac{\partial L}{\partial \mathbf{a}_1} \odot \mathbb{1}[\mathbf{z}_1 > 0]$$

其中 $\odot$ 是逐元素乘，$\mathbb{1}[\mathbf{z}_1 > 0]$ 是 ReLU 导数（正则为 1，负则为 0）。

**第五步：** 第一层权重的梯度

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \mathbf{z}_1} \cdot \mathbf{x}^T$$

$$\frac{\partial L}{\partial b_1} = \frac{\partial L}{\partial \mathbf{z}_1}$$

**至此，所有参数的梯度都计算完毕，用梯度下降更新参数：**

$$W_1 \leftarrow W_1 - \eta \cdot \frac{\partial L}{\partial W_1}, \quad W_2 \leftarrow W_2 - \eta \cdot \frac{\partial L}{\partial W_2}$$

---

## 第九章 · 梯度消失与梯度爆炸

这是深度学习工程中最重要的数值问题，根源在于链式法则的连乘性质。

### 9.1 梯度消失（Vanishing Gradient）

在深层网络中，梯度经过多层链式法则相乘后：

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z_n} \cdot \prod_{k=2}^{n} \frac{\partial z_k}{\partial z_{k-1}}$$

如果每一项都小于 1（比如 Sigmoid 的导数最大只有 0.25）：

$$0.25^{10} = 9.5 \times 10^{-7} \approx 0$$

梯度传到第一层时几乎为零，参数无法更新，网络停止学习。

```
第 n 层 →  第 n-1 层 →  ···  →  第 2 层  →  第 1 层
梯度：1.0    0.25        ···     0.001      0.000001
                                              ↑
                                         几乎消失！
```

**解决方案：**

- 使用 ReLU 替代 Sigmoid（导数为 1，不会连乘变小）
- 残差连接（ResNet）：$\mathbf{y} = F(\mathbf{x}) + \mathbf{x}$，梯度可以直接"跳过"层传递
- Layer Normalization / Batch Normalization：稳定每层的输出分布

---

### 9.2 梯度爆炸（Exploding Gradient）

相反，如果每一项都大于 1：

$$2^{100} = 1.27 \times 10^{30}$$

梯度变成天文数字，参数更新幅度极大，训练完全发散。

**解决方案：**

- **梯度裁剪**（Gradient Clipping）：如果梯度的 L2 范数超过阈值，按比例缩小

$$\text{if } |\mathbf{g}|_2 > \tau: \quad \mathbf{g} \leftarrow \frac{\tau}{|\mathbf{g}|_2} \mathbf{g}$$

- 合适的权重初始化（如 He 初始化、Xavier 初始化）

---

## 第十章 · 二阶导数与 Hessian 矩阵（进阶）

### 10.1 二阶导数的直觉

一阶导数告诉你坡度（多陡），二阶导数告诉你**坡度的变化率**（往上弯还是往下弯）：

$$f''(x) > 0 \Rightarrow \text{向上弯（凸，谷底）}$$ $$f''(x) < 0 \Rightarrow \text{向下弯（凹，山顶）}$$ $$f''(x) = 0 \Rightarrow \text{拐点}$$

---

### 10.2 Hessian 矩阵

对多变量函数，Hessian 矩阵收集所有**二阶偏导数**：

$$H = \begin{bmatrix} \dfrac{\partial^2 f}{\partial x_1^2} & \dfrac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \ \dfrac{\partial^2 f}{\partial x_2 \partial x_1} & \dfrac{\partial^2 f}{\partial x_2^2} & \cdots \ \vdots & \vdots & \ddots \end{bmatrix}$$

Hessian 的特征值描述损失曲面的曲率：

- 所有特征值 > 0 → 局部极小值（训练目标）
- 所有特征值 < 0 → 局部极大值
- 特征值有正有负 → **鞍点**（深度学习中最常见的"卡住"情况）

---

### 10.3 在 AI 中的意义

**鞍点问题：**

```
      L
      │         ↑ 鞍点：某些方向是谷底，某些方向是山顶
      │   ↗─────┼─────↗
      │ ─────────○─────────  ← 在这个方向上是极大值
      │   ↘─────┼─────↘         在垂直方向上是极小值
      └──────────────────── θ
```

神经网络的损失曲面中鞍点比局部极小值多得多，SGD 由于噪声通常能自然逃脱鞍点，这也是深度学习实践中 SGD 效果不差的原因之一。

**二阶优化（牛顿法）：**

$$\theta \leftarrow \theta - H^{-1} \nabla L$$

使用 Hessian 的逆来自适应步长，理论上收敛更快，但计算 $H^{-1}$ 代价极高（$O(n^3)$），对百亿参数的模型完全不可行，所以 Adam 等方法用对角近似代替。
