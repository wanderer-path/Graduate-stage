# 信息论

## 第一章 · 信息量与自信息

### 1.1 信息的直觉

信息论由 Claude Shannon 于 1948 年创立，核心问题是：**一条消息携带了多少信息？**

Shannon 的洞见：**一件事越不可能发生，它发生时携带的信息量越大。**

```
"太阳今天从东方升起"   → 概率极高 → 信息量极少（废话）
"今天下了一场流星雨"   → 概率较低 → 信息量较多
"明天地球爆炸"         → 概率极低 → 信息量极大
```

---

### 1.2 自信息（Self-Information）

事件 $x$ 的自信息（信息量）定义为：

$$I(x) = -\log P(x)$$

通常取以 2 为底的对数，单位是 **比特（bit）**；取自然对数，单位是 **奈特（nat）**，AI 中更常用 nat。

**理解这个公式：**

$$P(x) = 1 \Rightarrow I(x) = -\log 1 = 0 \quad \text{（必然发生，毫无信息）}$$ $$P(x) = 0.5 \Rightarrow I(x) = -\log_2 0.5 = 1 \text{ bit}$$ $$P(x) = 0.01 \Rightarrow I(x) = -\log_2 0.01 \approx 6.64 \text{ bits}$$

```
信息量 I(x)
    │\
    │ \
    │  \
    │   \___
    │       ───────
    └──────────────── P(x)
    0    0.5    1.0

概率越低，信息量越高（反比关系）
```

**为什么用负对数？** 三个原因：

1. $P(x) \in (0,1]$，$-\log P(x) \geq 0$，保证信息量非负
2. $\log$ 把乘法变加法：独立事件同时发生的信息量 $= I(x) + I(y)$（可加性）
3. 与概率的直觉一致：$P$ 越小，$I$ 越大

---

## 第二章 · 熵（Shannon Entropy）

### 2.1 定义

熵是自信息的**期望值**，衡量整个概率分布的**平均不确定性**：

$$H(X) = E[I(X)] = -\sum_{x} P(x) \log P(x)$$

连续分布（微分熵）：

$$H(X) = -\int p(x) \log p(x) , dx$$

**约定：** $0 \log 0 = 0$（因为 $\lim_{p \to 0} p \log p = 0$）

---

### 2.2 熵的直觉：不确定性的度量

**例 1：** 抛一枚公平硬币，$P(\text{正}) = P(\text{反}) = 0.5$

$$H = -(0.5\log_2 0.5 + 0.5\log_2 0.5) = -(-0.5 - 0.5) = 1 \text{ bit}$$

**例 2：** 抛一枚偏硬币，$P(\text{正}) = 0.9$，$P(\text{反}) = 0.1$

$$H = -(0.9\log_2 0.9 + 0.1\log_2 0.1) \approx 0.469 \text{ bits}$$

**例 3：** 完全确定的事件，$P(\text{正}) = 1$

$$H = -(1 \cdot \log_2 1) = 0 \text{ bits}$$

```
H(bits)
  1.0 │        ▲ 最大（最不确定）
      │       ███
  0.5 │      ██ ██
      │     ██   ██
  0.0 │────██     ██────
      └──────────────── p（正面概率）
         0   0.5   1.0
         ↑         ↑
      完全确定   完全确定
      （总反面） （总正面）
```

---

### 2.3 熵的三条重要性质

**① 非负性：** $H(X) \geq 0$，不确定性不能为负

**② 最大熵原理：** 均匀分布时熵最大

$$H \leq \log K \quad \text{（K 为可能取值数）}$$

当且仅当所有结果等概率时取等号。

**③ 可加性（独立时）：**

$$H(X, Y) = H(X) + H(Y) \quad \text{若 X, Y 独立}$$

---

### 2.4 在 AI 中的含义

**模型输出的熵衡量模型的确信程度：**

```
高熵输出（不确定）：          低熵输出（确定）：
p = [0.2, 0.2, 0.2, 0.4]    p = [0.01, 0.01, 0.01, 0.97]
H ≈ 1.92 bits                H ≈ 0.24 bits

模型在犹豫                    模型很确定
```

**熵正则化（Entropy Regularization）：** 在强化学习中，鼓励策略输出高熵（更多探索），防止过早收敛到次优行为：

$$\mathcal{L} = \mathcal{L}_{task} - \alpha \cdot H(\pi(\cdot|s))$$

**LLM 中的困惑度（Perplexity）：**

$$\text{Perplexity} = 2^{H(p)} = 2^{-\frac{1}{N}\sum_i \log_2 P(x_i)}$$

困惑度越低，模型对真实数据的预测越准确，语言模型的标准评测指标。

## 第三章 · 联合熵与条件熵

### 3.1 联合熵

两个随机变量 $(X, Y)$ 的联合不确定性：

$$H(X, Y) = -\sum_{x,y} P(x, y) \log P(x, y)$$

**链式法则：**

$$H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$$

联合的不确定性 = 先知道 $X$ 的不确定性 + 在已知 $X$ 后 $Y$ 的不确定性。

---

### 3.2 条件熵

已知 $X$ 后，$Y$ 的**剩余不确定性**：

$$H(Y|X) = -\sum_{x,y} P(x,y) \log P(y|x) = \sum_x P(x) H(Y|X=x)$$

**直觉：** 知道了 $X$ 之后，$Y$ 还有多少不确定性？

$$H(Y|X) \leq H(Y)$$

知道额外信息只会减少（或保持）不确定性，永远不会增加。

---

### 3.3 信息的叠加关系图

```
┌─────────────────────────────────────────┐
│               H(X, Y)                   │
│  ┌──────────────────┐ ┌──────────────┐  │
│  │     H(X)         │ │    H(Y)      │  │
│  │    ┌─────────────┼─┼──────┐       │  │
│  │    │    I(X;Y)   │ │      │       │  │
│  │    │   互信息    │ │      │       │  │
│  │    └─────────────┼─┼──────┘       │  │
│  │  H(X|Y)          │ │    H(Y|X)    │  │
│  └──────────────────┘ └──────────────┘  │
└─────────────────────────────────────────┘

H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)
I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)
```

---

## 第四章 · 互信息（Mutual Information）

### 4.1 定义

互信息衡量两个随机变量之间**共享的信息量**，即知道一个变量后，另一个变量不确定性减少了多少：

$$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$

展开为：

$$I(X; Y) = \sum_{x,y} P(x,y) \log \frac{P(x,y)}{P(x)P(y)}$$

**性质：**

- $I(X;Y) \geq 0$，等号成立当且仅当 $X$、$Y$ 独立
- $I(X;Y) = I(Y;X)$，对称性
- $I(X;X) = H(X)$，自身与自身的互信息 = 自身的熵

---

### 4.2 互信息 vs 相关系数

||互信息 $I(X;Y)$|相关系数 $\rho(X,Y)$|
|---|---|---|
|捕获关系类型|任意依赖（线性+非线性）|仅线性关系|
|值域|$[0, +\infty)$|$[-1, 1]$|
|独立时|$= 0$|$= 0$|
|非线性依赖|能检测到|可能为 0（漏检）|

```
反例：X ~ U[-1,1]，Y = X²

ρ(X,Y) = 0  ← 相关系数说"无关"（错！）
I(X;Y) > 0  ← 互信息说"有关"（正确！）
```

---

### 4.3 在 AI 中的核心应用

**① 对比学习（CLIP、SimCLR）：**

InfoNCE 损失的理论基础就是最大化互信息。CLIP 的目标：使图片和对应文字之间的互信息最大，使图片与不对应文字之间的互信息最小。

$$\mathcal{L}_{InfoNCE} = -E\left[\log \frac{e^{f(x)^T g(y)/\tau}}{\sum_{j} e^{f(x)^T g(y_j)/\tau}}\right]$$

这个损失是 $I(X;Y)$ 的下界，最大化它就是在最大化互信息。

**② 特征选择：**

选择与标签 $Y$ 互信息最大的特征 $X_i$，等价于选择对预测最有用的特征。

**③ 信息瓶颈（Information Bottleneck）：**

$$\min_{p(\tilde{x}|x)} \underbrace{I(X; \tilde{X})}_{\text{压缩}} - \beta \underbrace{I(\tilde{X}; Y)}_{\text{保留预测力}}$$

压缩输入 $X$ 为紧凑表示 $\tilde{X}$，同时保留对 $Y$ 的预测能力。这被用于理解神经网络"学到了什么"。

## 第五章 · 交叉熵（Cross-Entropy）

### 5.1 定义

设真实分布为 $P$，用分布 $Q$ 来编码 $P$ 的信息，所需的平均比特数：

$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

**与自身熵的关系：**

$$H(P, Q) \geq H(P)$$

用"错误的"分布 $Q$ 编码，永远比用真实分布 $P$ 编码需要更多比特。

---

### 5.2 交叉熵的直觉

```
真实分布 P（数据真实规律）：
"猫"→0.6, "狗"→0.3, "鱼"→0.1

模型分布 Q（模型的预测）：
情形 A（好模型）: "猫"→0.55, "狗"→0.35, "鱼"→0.10
情形 B（差模型）: "猫"→0.1,  "狗"→0.1,  "鱼"→0.8

H(P, QA) 较小 ← 预测接近真实，编码高效
H(P, QB) 较大 ← 预测偏离真实，编码低效
```

**训练模型 = 调整 $Q$（模型参数），使 $H(P, Q)$ 最小，即让模型分布尽量接近真实分布。**

---

### 5.3 交叉熵损失的展开

对于分类任务，真实标签是 one-hot 向量（如 $y = [0, 1, 0, 0]$），则：

$$H(y, \hat{y}) = -\sum_k y_k \log \hat{y}_k = -\log \hat{y}_{c}$$

其中 $c$ 是真实类别。整个数据集上的平均交叉熵损失：

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^N \log \hat{y}_{c_i}$$

**直觉极其简单：对正确类别的预测概率取负对数，越接近 1，损失越小。**

```
预测正确类别概率  →  损失
      0.99       →   0.01  （几乎完美）
      0.50       →   0.69  （不确定）
      0.10       →   2.30  （几乎全错）
      0.01       →   4.60  （完全错误）
```

---

### 5.4 二元交叉熵（Binary Cross-Entropy）

二分类任务（Sigmoid + 交叉熵）：

$$\mathcal{L} = -[y \log \hat{y} + (1-y)\log(1-\hat{y})]$$

- 若 $y=1$：损失 $= -\log\hat{y}$，预测 $\hat{y}$ 越大越好
- 若 $y=0$：损失 $= -\log(1-\hat{y})$，预测 $\hat{y}$ 越小越好

**在 AI 中：** 情感分析、垃圾邮件检测、文档相关性判断等二分类任务的标准损失函数。

---

## 第六章 · KL 散度（Kullback-Leibler Divergence）

### 6.1 定义

KL 散度衡量用分布 $Q$ 来近似分布 $P$ 时的**信息损失**：

$$D_{KL}(P | Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)} = E_P!\left[\log\frac{P}{Q}\right]$$

连续形式：

$$D_{KL}(P | Q) = \int p(x) \log \frac{p(x)}{q(x)} , dx$$

---

### 6.2 KL 散度与交叉熵的关系

$$D_{KL}(P | Q) = H(P, Q) - H(P)$$

$$\underbrace{D_{KL}(P | Q)}_{\text{额外代价}} = \underbrace{H(P,Q)}_{\text{用 Q 编码 P 的总代价}} - \underbrace{H(P)}_{\text{最优编码代价}}$$

**KL 散度 = 因为用了错误的分布 Q 而多花的额外比特数。**

由于 $H(P)$ 是固定的（与模型无关），**最小化交叉熵 $\Leftrightarrow$ 最小化 KL 散度**。

---

### 6.3 KL 散度的四条关键性质

**① 非负性（Gibbs 不等式）：**

$$D_{KL}(P | Q) \geq 0$$

等号成立当且仅当 $P = Q$（逐点相等）。

**证明直觉：** 由 Jensen 不等式，$-\log$ 是凸函数，期望在函数外 $\leq$ 函数在期望外。

**② 非对称性（极其重要）：**

$$D_{KL}(P | Q) \neq D_{KL}(Q | P)$$

KL 散度不是距离！方向不同，含义不同：

```
P = 真实分布（高斯混合，双峰）
Q = 近似分布（单个高斯）

D_KL(P‖Q)：Q 必须覆盖 P 的所有质量 → Q 会变宽，覆盖两个峰之间的空洞
D_KL(Q‖P)：Q 只需覆盖 P 的一个高概率区域 → Q 会坍缩到 P 的某一个峰

              P                   Q 拟合 P‖Q        Q 拟合 Q‖P
         ┌─┐   ┌─┐              ┌───────┐            ┌─┐
         │ │   │ │              │       │            │ │
    ─────┘ └───┘ └─────    ─────┘       └─────   ────┘ └──────
    两峰之间有谷            Q 必须跨越两峰          Q 只覆盖一峰
```

**③ 与交叉熵等价（训练时）：**

$$\arg\min_\theta D_{KL}(P | Q_\theta) = \arg\min_\theta H(P, Q_\theta)$$

因为 $H(P)$ 与 $\theta$ 无关，优化时可以忽略。

**④ KL 散度是 $f$-散度的特例：** 广义信息度量的一个具体实例。

---

### 6.4 在 AI 中的核心应用（极其重要）

**① VAE 的损失函数：**

$$\mathcal{L}_{VAE} = \underbrace{E[\log p(\mathbf{x}|\mathbf{z})]}_{\text{重建}} - \underbrace{D_{KL}(q(\mathbf{z}|\mathbf{x}) | p(\mathbf{z}))}_{\text{让隐变量接近标准正态}}$$

KL 项约束编码器输出的隐变量分布接近 $\mathcal{N}(0, I)$，使潜空间连续可插值。

**② RLHF 中的 KL 约束：**

PPO 训练语言模型时，防止模型偏离参考模型（SFT 模型）太远：

$$\mathcal{L}_{RLHF} = E[r(x,y)] - \beta \cdot D_{KL}(\pi_\theta | \pi_{ref})$$

KL 惩罚项 $\beta$ 控制模型在追求高奖励时不能"走样"太多，这是 RLHF 训练稳定的关键。

**③ 知识蒸馏（Knowledge Distillation）：**

用大模型（teacher）的输出分布 $P_{teacher}$ 来指导小模型（student）：

$$\mathcal{L}_{KD} = D_{KL}(P_{teacher} | P_{student})$$

让小模型尽量模仿大模型的"软标签"（概率分布），而非只学习硬标签（0/1），包含更多信息。

**④ 扩散模型的变分下界：**

DDPM 的训练目标也是 KL 散度的形式，最大化 ELBO 等价于最小化每一步去噪过程中真实后验与模型近似之间的 KL 散度。

## 第七章 · JS 散度（Jensen-Shannon Divergence）

### 7.1 KL 散度的问题

KL 散度不对称，且当 $P$ 和 $Q$ 支撑集不重叠时，$D_{KL}(P|Q) = +\infty$（因为 $\log \frac{P}{Q}$ 中 $Q=0$ 而 $P>0$）。

这在 GAN 训练中导致梯度消失问题：生成分布与真实分布完全不重叠时，KL 散度无穷大，梯度无法传递。

---

### 7.2 定义

JS 散度是 KL 散度的**对称化**版本，以混合分布 $M = \frac{P+Q}{2}$ 为中间点：

$$D_{JS}(P | Q) = \frac{1}{2}D_{KL}(P | M) + \frac{1}{2}D_{KL}(Q | M)$$

**性质：**

- $D_{JS}(P|Q) = D_{JS}(Q|P)$：**对称**
- $0 \leq D_{JS}(P|Q) \leq \log 2$：**有界**
- $\sqrt{D_{JS}}$ 是一个真正的距离度量（满足三角不等式）

---

### 7.3 在 GAN 中的角色

原始 GAN 的判别器（最优时）等价于最小化 JS 散度：

$$\min_G D_{JS}(P_{data} | P_G)$$

但 JS 散度在两个分布不重叠时仍然是常数（$\log 2$），梯度为 0，训练仍然困难。这就是 Wasserstein GAN（WGAN）出现的原因——用 Wasserstein 距离替代 JS 散度，解决了 GAN 训练中的梯度消失问题。

---

## 第八章 · 信息瓶颈理论（Information Bottleneck）

### 8.1 核心思想

Tishby 等人提出：神经网络的学习过程可以用信息论来理解。网络的中间层表示 $\tilde{X}$ 试图在两个目标之间取得平衡：

$$\min_{p(\tilde{x}|x)} \underbrace{I(X; \tilde{X})}_{\text{最小化：压缩输入}} - \beta \underbrace{I(\tilde{X}; Y)}_{\text{最大化：保留预测力}}$$

- **压缩（Compression）：** 丢弃与预测无关的信息，减少 $I(X;\tilde{X})$
- **预测（Prediction）：** 保留对标签有用的信息，增大 $I(\tilde{X};Y)$

---

### 8.2 神经网络训练的信息论视角

```
训练过程中各层的信息平面（I(X;T) vs I(T;Y)）：

I(T;Y)
  ↑  ·  ·  ·         ← 上方：预测力强
  │         · ·
  │           · ·
  │             · ·   ← 训练后期：压缩阶段
  │              · ·  （有争议，但提供了直觉）
  └──────────────────→ I(X;T)
  少          多
（压缩多）  （压缩少）

拟人化理解：
网络先快速记住数据（拟合阶段）
然后逐渐"遗忘"无关细节，只保留对任务有用的信息（压缩阶段）
```

**在 AI 中的影响：**

- 解释为什么过拟合时模型记住了噪声（$I(X;\tilde{X})$ 过大）
- 正则化、Dropout 等可以理解为增强压缩，减少 $I(X;\tilde{X})$
- 对于 Transformer，注意力机制可以看作选择性地传递互信息最大的信息

---

## 第九章 · 编码理论基础

### 9.1 香农第一定理（数据压缩极限）

**定理：** 对随机变量 $X$，任何无损编码方案的平均码长 $\geq H(X)$（香农熵）。

存在编码方案使得平均码长任意接近 $H(X)$，但不能低于它。

**熵 = 信息的理论压缩极限。**

```
英文字母（26个）：
  若均匀：H = log₂26 ≈ 4.7 bits/字母
  考虑频率：H ≈ 4.1 bits/字母（e 最常见，所以 e 可以用短码）
  考虑上下文依赖：H ≈ 1.3 bits/字母（u 在 q 后几乎必然出现）

LLM 做的事：估计尽可能精确的条件概率，使困惑度趋向理论下界
```

---

### 9.2 香农第二定理（信道容量）

信道容量 $C$（单位：bits/symbol）：

$$C = \max_{p(x)} I(X; Y)$$

即通过优化输入分布，最大化输入与输出之间的互信息，这是可靠传输信息的速率上限。

**在 AI 中的类比：**

- 神经网络的层可以看作"信道"，信道容量对应该层能传递多少有效信息
- Dropout 降低了"信道容量"，迫使网络学习更鲁棒的表示

---

## 第十章 · 各概念的统一视角

### 10.1 所有度量的关系总图

```
给定两个分布 P（真实）和 Q（模型）：

                P(x)
H(P) = -Σ P(x)log P(x)           ← P 的固有不确定性（与 Q 无关）

                Q(x)
H(P,Q) = -Σ P(x)log Q(x)         ← 用 Q 为 P 编码的代价

D_KL(P‖Q) = Σ P(x)log P(x)/Q(x)  ← 额外代价 = H(P,Q) - H(P)

D_JS(P‖Q) = ½D_KL(P‖M)+½D_KL(Q‖M) ← 对称版本，M=(P+Q)/2

I(X;Y) = D_KL(P(x,y) ‖ P(x)P(y)) ← 联合分布与独立分布的 KL 散度

关系式：
H(P,Q) = H(P) + D_KL(P‖Q)
I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)
```
