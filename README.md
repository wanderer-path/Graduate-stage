## 🎯 关于本项目 About

> **一个研究生在学期间的系统化知识管理仓库。**  
> 将零散的学习笔记、科研思路、项目实践和个人成长整合为结构化的知识体系，方便回顾、检索与分享。

### 核心理念

| 原则 | 说明 |
|------|------|
| **📝 记录优先** | 先写下来，再整理 — 捕捉每一个灵感和收获 |
| **🔗 知识互联** | 利用 Obsidian 的 Wiki 链接和标签体系，构建个人知识图谱 |
| **📊 结构化输出** | 每一份笔记、记录都遵循一致的格式，方便日后检索 |
| **🔄 持续迭代** | 内容不是一次成型，而是伴随研究生涯不断更新和深化 |

### 各模块说明

<details open>
<summary><h4 style="display: inline;">📖 学习笔记 — Study Notes</h4></summary>

**用途：** 记录课程学习、技术书籍、在线课程、论文阅读等过程中产生的笔记。

| 内容类型 | 说明 |
|---------|------|
| 📚 课程笔记 | 研究生课程的核心概念、作业思路、考试复习 |
| 📄 论文精读 | 每篇精读论文的背景、方法、实验、思考 |
| 🛠️ 技术备忘 | 编程语言、框架、工具的学习与实践技巧 |
| ❓ 问题集锦 | 学习过程中遇到的典型问题和解决方案 |

</details>

<details open>
<summary><h4 style="display: inline;">🔬 科研记录 — Research Records</h4></summary>

**用途：** 完整记录科研过程，包括研究方向探索、实验设计、结果分析和论文写作。

| 内容类型 | 说明 |
|---------|------|
| 💡 研究方向 | 调研中的研究方向和兴趣点 |
| 🧪 实验记录 | 每次实验的设计、参数、结果和分析 |
| 📊 数据与图表 | 实验数据、可视化结果 |
| ✍️ 论文写作 | 摘要、引言、方法论等写作草稿与修改记录 |
| 🗣️ 组会报告 | 组会 PPT 和汇报内容存档 |

</details>

<details open>
<summary><h4 style="display: inline;">🛠️ 项目实践 — Projects</h4></summary>

**用途：** 存放工程项目、竞赛代码、开源贡献等实践内容。

| 内容类型 | 说明 |
|---------|------|
| 🏗️ 工程项目 | 课程大作业、研究原型系统 |
| 🏆 竞赛项目 | 各类算法/数据竞赛的代码与方案 |
| 🤝 开源贡献 | 参与开源项目的 PR、Issue 和讨论 |
| 🔧 工具脚本 | 日常开发中的实用工具和脚本 |

</details>

<details open>
<summary><h4 style="display: inline;">🌱 个人成长 — Personal Growth</h4></summary>

**用途：** 记录研究生期间的软技能提升、职业规划和自我反思。

| 内容类型 | 说明 |
|---------|------|
| 🎯 目标管理 | 学期目标、周计划、日计划 |
| 📈 技能图谱 | 技能树的构建与评估 |
| 💬 沟通与表达 | 汇报技巧、写作能力、英语学习 |
| 🔄 回顾与反思 | 阶段性总结、经验教训 |

</details>

## 🛠️ 工具链 Toolchain

| 工具                                                                                         | 用途                         |
| ------------------------------------------------------------------------------------------ | -------------------------- |
| <img src="https://simpleicons.org/icons/obsidian.svg" width="16" height="16"> **Obsidian** | 笔记编写与知识管理（Wiki 链接、标签、图谱视图） |

### Obsidian 配置亮点

- **标签体系**: 统一的标签规范，便于跨模块检索
- **模板系统**: 论文笔记、实验记录、会议纪要等使用标准化模版
- **双向链接**: 通过 `[[Wiki Link]]` 建立知识点之间的关联
- **图谱视图**: 可视化知识连接，发现意外关联
