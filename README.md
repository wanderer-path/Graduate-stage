## 📂 目录结构 Structure

```
Graduate/
├── 📖 学习笔记/           # 课程学习与知识沉淀
├── 🔬 科研记录/           # 科研过程全记录
├── 🛠️ 项目实践/           # 工程项目与代码实践
├── 🌱 个人成长/           # 软技能与职业发展
└── README.md             # 本文件
```

### 四大模块说明

<details open>
<summary><h4>📖 学习笔记 — Study Notes</h4></summary>

**用途**：记录课程学习、技术框架、在线课程、论文精读等过程中产生的笔记。

| 内容类型 | 说明 |
|---------|------|
| 📚 课程笔记 | 研究生课程的核心概念、作业思路、考试复习 |
| 📄 论文精读 | 每篇精读论文的背景、方法、实验、思考 |
| 🛠️ 技术备忘 | 编程语言、框架、工具的学习与实践技巧 |
| ❓ 问题集锦 | 学习过程中遇到的典型问题和解决方案 |

</details>

<details open>
<summary><h4>🔬 科研记录 — Research Records</h4></summary>

**用途**：完整记录科研过程，包括研究方向探索、实验设计、结果分析和论文写作。

| 内容类型 | 说明 |
|---------|------|
| 💡 研究方向 | 调研中的研究方向和兴趣点 |
| 🧪 实验记录 | 每次实验的设计、参数、结果和分析 |
| 📊 数据与图表 | 实验数据、可视化结果 |
| ✍️ 论文写作 | 摘要、引言、方法论等写作草稿与修改记录 |

</details>

<details open>
<summary><h4>🛠️ 项目实践 — Projects</h4></summary>

**用途**：存放工程项目、竞赛代码、开源贡献等实践内容。

| 内容类型 | 说明 |
|---------|------|
| 🏗️ 工程项目 | 课程大作业、研究原型系统 |
| 🏆 竞赛项目 | 各类算法/数据竞赛的代码与方案 |
| 🤝 开源贡献 | 参与开源项目的 PR、Issue 和讨论 |
| 🔧 工具脚本 | 日常开发中的实用工具和脚本 |

</details>

<details open>
<summary><h4>🌱 个人成长 — Personal Growth</h4></summary>

**用途**：记录研究生期间的软技能提升、职业规划和自我反思。

| 内容类型 | 说明 |
|---------|------|
| 🎯 目标管理 | 学期目标、周计划、日计划 |
| 📈 技能图谱 | 技能树的构建与评估 |
| 💬 沟通与表达 | 汇报技巧、写作能力、英语学习 |
| 🔄 回顾与反思 | 阶段性总结、经验教训 |

</details>
