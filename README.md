## 🤔 为什么建立这个知识库？

研究生阶段会产生大量碎片化的知识、灵感、实验记录和项目代码。零散存放不仅难以检索，更无法形成知识连接。

**本仓库的解决方案**：建立结构化的知识管理体系，让每一份记录都能被追溯、连接和复用。

| 当前痛点          | 本仓库的解决方案                  |
| ------------- | ------------------------- |
| 📝 "笔记分散在各处"  | 四大模块统一管理 — 学习/科研/项目/成长    |
| 🔍 "找不到以前的内容" | Obsidian 双向链接 + 标签体系，随手可查 |
| 📊 "数据无法复用"   | 结构化存储格式，代码和数据可直接调用        |
| 🔄 "重复造轮子"    | 标准化笔记模板，复用率提升 10x+        |

### Obsidian 配置亮点

- **标签体系**: 统一的标签规范（#学习 #科研 #项目 #成长），便于跨模块检索
- **模板系统**: 论文笔记、实验记录、会议纪要等使用标准化模版
- **双向链接**: 通过 `[[Wiki Link]]` 建立知识点之间的关联
- **图谱视图**: 可视化知识连接，发现意外关联
- **Dataview**: 支持元数据查询，实现动态知识索引
