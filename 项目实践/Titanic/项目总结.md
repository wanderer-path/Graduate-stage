## 📋 项目概述

> **目标**：根据泰坦尼克号乘客的个人信息（如船舱等级、性别、年龄等），预测该乘客是否在船难中幸存。
>
> 这是 Kaggle 上最经典的入门竞赛，适合作为机器学习分类问题的起点项目。

| 项目信息 | 内容 |
|---------|------|
| 🏆 **竞赛平台** | Kaggle — Titanic: Machine Learning from Disaster |
| 📊 **任务类型** | 二分类（生还 / 未生还） |
| 🎯 **评价指标** | Accuracy（准确率） |
| 👥 **训练样本** | 891 人（含标签） |
| 🔮 **测试样本** | 418 人（不含标签） |
| 📦 **特征数量** | 初始 12 列，工程后 8 维特征 |

## 🧠 分析流程 Pipeline

### 一、探索性数据分析 (EDA)

初步探索特征与生存率之间的关系：

| 特征 | 发现 |
|------|------|
| **Sex** 🚻 | 女性生还率 **74.2%** vs 男性 **18.9%** — 最显著的特征 |
| **Pclass** 🏛️ | 头等舱 **63.0%** > 二等舱 **47.3%** > 三等舱 **24.2%** |
| **Age** 📅 | 年龄分布呈右偏，儿童生还率偏高 |

### 二、数据清洗

```
缺失值处理：
  - Age      → 177 缺失 → 用中位数填充
  - Cabin    → 687 缺失 → 直接删除（缺失过多）
  - Embarked → 2 缺失   → 用众数(S)填充
  - Fare     → 1 缺失   → 用中位数填充

删除列：Cabin, Ticket, Name, PassengerId
```

### 三、特征工程

| 新特征 | 构造方式 | 目的 |
|--------|---------|------|
| **Sex** | `male→0, female→1` | 将文本编码为数值 |
| **Embarked** | `S→0, C→1, Q→2` | 将文本编码为数值 |
| **FamilySize** | `SibSp + Parch + 1` | 捕捉家庭规模影响 |
| **IsAlone** | `FamilySize == 1` | 独自一人是否影响生存 |
| **AgeBand** | 分箱：`[0-12, 12-18, 18-35, 35-60, 60-100]` | 将连续年龄离散化 |

```
特征维度：12 列原始特征 → 清洗后 8 维有效特征
```

### 四、模型训练

使用了两种模型进行对比：

| 模型 | 交叉验证准确率 | 特点 |
|------|--------------|------|
| 🔵 **逻辑回归 (Logistic Regression)** | 基线模型 | 简单、可解释性强，需标准化 |
| 🟢 **随机森林 (Random Forest)** | ⭐ 更高 | 能捕获非线性关系，自带特征重要性 |

### 五、超参数调优

使用 **GridSearchCV**（5 折交叉验证）对随机森林进行调参：

```python
param_grid = {
    'n_estimators':      [100, 200, 300],
    'max_depth':         [3, 5, 7, None],
    'min_samples_split': [2, 5, 10]
}
```

输出最优参数组合及对应的交叉验证准确率。

### 六、预测与提交

- 用最优模型对测试集 418 名乘客进行预测
- 生成与 Kaggle 提交格式一致的预测文件

## 📊 关键发现 Key Insights

```
特征重要性排序（随机森林）：
  1. Sex        ⭐⭐⭐⭐⭐  性别是决定性因素
  2. Fare       ⭐⭐⭐⭐    票价（反映社会经济地位）
  3. Pclass     ⭐⭐⭐⭐    船舱等级
  4. Age        ⭐⭐⭐      年龄
  5. FamilySize ⭐⭐        家庭规模
  6. IsAlone    ⭐         是否独身
  7. Embarked   ⭐         登船港口
  8. AgeBand    ⭐         年龄分组
```

### 业务含义

1. **"妇女儿童优先"真实体现在数据中** — 性别是最强预测因子
2. **头等舱生存率是三等舱的 2.6 倍** — 社会经济地位直接影响生存机会
3. **家庭规模适中者生存率较高** — 独自一人和过大家庭都不利
